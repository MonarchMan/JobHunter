# 005 职位同步流水线规格

> 状态：Implemented
> 依赖：001, 002, 003, 004

## 目标

把来源适配器输出可靠地转换为符合当前求职意向的原始证据、标准化职位、历史修订和状态变化。

## 功能需求

- **SYNC-001**：每次同步必须创建 SyncRun，记录来源、触发方式、时间、状态、覆盖度、游标、统计、适配器/标准化/同步策略版本和脱敏配置哈希。
- **SYNC-002**：同一来源同时最多运行一个同步；重复触发必须返回已有任务/运行或明确冲突。
- **SYNC-003**：每个发现职位必须先完成标准化、内部职位类别归一化和入库范围判断；只有符合当前画像意向的职位才保存原始证据并合并为标准化职位。
- **SYNC-004**：相同 `(sourceId, externalJobId)` 且内容哈希相同时，只更新观察和 lastSeen，不创建修订。
- **SYNC-005**：内容哈希变化时必须原子更新当前投影、创建 Revision 和必要状态事件。
- **SYNC-006**：每次成功观察必须将 stale/closed 职位恢复 active、清零 missingCount。
- **SYNC-007**：仅 coverage=`complete` 的成功或可安全完成运行才能处理未观察职位；partial/failed/cancelled 不得增加缺失。
- **SYNC-008**：达到来源策略阈值时 active→stale→closed；明确 not_found 可按策略直接关闭。
- **SYNC-009**：只有同步成功且游标有效时才提交 cursorOut；失败时保留 cursorIn。
- **SYNC-010**：新 Revision 不得自动创建匹配、职位理解或 Agent 建议任务；匹配只能由用户针对具体职位显式触发。关闭自动任务不得删除历史结果。
- **SYNC-011**：单个职位解析失败必须隔离并计数，不能写入不完整 Job。若已知 externalJobId 且对应已有职位，必须保存原始证据并将其标记为本轮已观察，避免误判关闭；无法确定失败项身份时整轮 coverage 必须降为 partial。
- **SYNC-012**：运行结束必须校验计数一致性，并更新来源健康状态。
- **SYNC-013**：`skippedOutOfScope`、`skippedNonDomestic`、`skippedUnknownRegion` 是已成功处理的业务过滤结果；只要采集覆盖完整且没有运行错误或无法安全归属的隔离项，就不得因此把运行降为 partial 或累计来源失败次数。
- **SYNC-014**：来源互斥记录必须可恢复。创建新运行时应结束超过 Worker 租约恢复窗口的孤儿 running 记录；仍在恢复窗口内的运行才返回明确冲突，避免进程中断永久阻塞来源。
- **SYNC-015**：列表同步不得调用详情接口。deferred 来源只为已通过地域和求职意向过滤的职位创建幂等详情补全任务；详情失败不得改变 SyncRun coverage 或来源健康。
- **SYNC-016**：来源健康必须区分运行级列表失败、分页覆盖不完整和可归属单条隔离。完整列表成功必须清零列表失败；少量可归属隔离只记录数据质量诊断；临时 partial 必须由任务队列退避重试。
- **SYNC-017**：SyncRun 必须保存结构化覆盖证据；单条隔离必须保存 externalJobId、失败阶段、分类、脱敏摘要和原始记录引用。

## 质量需求

- **SYNC-Q01**：同步必须流式处理，不能要求将全部职位保存在内存。
- **SYNC-Q02**：单职位数据库事务短小，网络请求不在事务中。
- **SYNC-Q03**：重复运行、任务恢复和同一原始记录重放必须幂等。
- **SYNC-Q04**：原始数据和错误日志必须经过大小限制及敏感字段处理。

## 验收场景

1. 首次完整同步 3 个职位，创建 3 Job、3 Revision、3 Observation，统计一致。（SYNC-001..005）
2. 相同数据重跑只新增 Observation、更新 lastSeen，不新增 Revision。（SYNC-004）
3. 一条 JD 变化仅该职位新增 Revision，且不会自动创建匹配或模型任务。（SYNC-005,010）
4. 第二页网络失败时运行 partial，未出现的旧职位 missingCount 不变。（SYNC-007）
5. 职位连续完整缺失达到阈值后依次 stale/closed，并记录证据。（SYNC-008）
6. closed 职位再次出现后恢复 active，历史修订和匹配仍存在。（SYNC-006）
7. 中途取消不提交新游标，不基于未见集合改变状态。（SYNC-007,009）
8. 单条详情解析失败但 externalJobId 对应已有职位时，该职位保持已观察且内容不更新；单条无 ID 且无法生成安全指纹时整轮降为 partial。（SYNC-011）
9. 完整采集包含大量意向外或地域过滤项时，运行仍为 succeeded、来源为 healthy，过滤数量只进入统计。（SYNC-013）
10. Worker 中断遗留的 running 记录超过恢复窗口后，新同步会先结束孤儿记录并正常启动；窗口内并发仍返回已有运行。（SYNC-002,014）
11. deferred 来源先完成列表同步和 intake，再为接收职位创建详情任务；详情任务失败时列表运行仍保持完整且不增加来源失败。（SYNC-015）
12. temporary partial 保存运行证据后触发任务重试；重试后的完整列表成功清零失败计数。（SYNC-016,017）
