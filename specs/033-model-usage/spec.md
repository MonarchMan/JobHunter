# 033 模型用量统计

> 状态：Implemented
> 依赖：008, 011

用量视图排除 transportError=network 的请求，列表、筛选候选、总计、分组和趋势保持同一范围；原始账本与 Agent 诊断保留。总成本只显示已知费用合计或未知值，不显示未定价请求次数提示，包括悬停提示。取消、超时、HTTP 错误和输出校验失败不因此隐藏。（USG-002, USG-003, USG-004）

页面范围更新：USG-001/007 的应用切换取消，页面仅统计本项目账本；顶部保留右对齐的币种、供应商、模型和时间筛选，忽略旧 URL 的 application 参数。

币种仅控制费用显示，默认 USD，切换时不得隐藏其他原币种的请求、模型或 Tokens。所有已知费用按 MODEL_USD_TO_CNY_RATE（默认 7.2）统一换算为显示币种；总计、分组、趋势、请求和价格表遵循相同规则。原始金额与币种保持不变，不回填未知用量或价格；部分请求未定价时展示已知费用合计。（USG-001, USG-002, USG-003, USG-008）

- **USG-001**：任务页增加用量统计 tab，保留原任务与 Agent 运行视图。提供当天、近 24 小时、7/14/30 天（Asia/Shanghai 自然日）、全部、应用、供应商、模型、HTTP 状态码和费用显示币种。
- **USG-002**：按已持久化逐请求快照统计请求数、已知成本、输入加输出 Tokens、缓存命中率。输入已包含缓存读写，不重复相加；命中率为已完整上报缓存读取的请求的缓存读取总量/输入总量，不平均各请求百分比。未知用量、未定价必须提示，零值与未知区分。
- **USG-003**：提供按小时/天补零的 Tokens、请求、成本趋势，请求日志分页及模型汇总；所有统计使用同一筛选结果，分页不改变总计。金额保持原计价币种，不同原币种按显式汇率换算后汇总。
- **USG-004**：只读查询 common 所有的 Agent 逐请求快照，按 requestedAt 过滤，重复重试快照中的每个真实调用各计一次，不叠加运行级总计。缺少快照的历史运行单列提示，不伪造请求。运行状态不冒充 HTTP 状态，未采集的供应商/速度/首字延迟不推测。持久化在仓储适配器，用例依赖端口，无数据迁移。
- **USG-005**：移动端无页面横向溢出，图表有键盘可读数据，筛选和空状态可用。自动刷新沿用任务页刷新机制。
- **USG-006**：新增请求记录采集应用、供应商主机、HTTP 状态码、完整耗时、首个有效内容延迟和输出速度。OpenAI 兼容与 Anthropic 使用流式协议测量首字，不将响应头耗时或完整耗时冒充首字；非流式兼容响应的首字/生成速度为 null。供应商只保存主机，不保存路径、查询参数或凭据。格式协商、失败、取消和超时各次真实请求均保存；流中断不能作为成功输出。
- **USG-007**：以本机 CC Switch 完整用量页为布局参考：顶部左侧应用筛选，右侧供应商、级联模型和时间；四卡依次总成本、总请求数、真实消耗 Tokens、缓存命中率，右侧更多指标展开第二排新增输入、Output、创建、命中卡。趋势指标开关在图表右上，带悬停详情；下方依次请求日志、供应商、模型、设置，仅日志右侧显示状态码筛选。日志默认十列，另可开启缓存写入、命中率、总耗时、状态码；供应商/模型表列为名称、请求数、Tokens、成本、成功率、速度、首字，按请求数排序，每页 20 条。所有下拉框复用公共 SelectField，删除常驻说明，未知值用破折号及必要 tooltip 表达。
- **USG-008**：顶部提供费用显示币种选择，设置提供柱形/折线趋势和日志列选择，并展示实际请求价格快照。复用 JobHunter 的采集与定价来源，不引入 CC Switch 的本机会话扫描、代理、侧栏偏好或 models.dev 写入流程。支持当天、近 24 小时、7/14/30 天和全部时间。汇总速度按有效输出总量/生成时间总量计算（仅成功流式且输出至少 100），首字取成功流式请求中位数；真实测量不加估算符号。

USG-001/004 更新：增加供应商及真实 HTTP 状态码筛选；保留运行状态仅供内部诊断。旧快照可读但不回填无法还原的供应商、时延或状态。新增可选字段随原 JSON 快照保存，无旧数据写操作。

账本更新（取代 USG-004 的 JSON 存储约定）：

- **USG-009**：common 独立拥有 model_requests 请求账本；每次实际 HTTP 请求发起前生成 ID 并登记 running，结束后按同一 ID 更新 completed 与已知用量。协商、重试各自独立，重复保存不重复计费；请求结束即可查询，不等待 Agent 运行结束。进程中断后的未完成请求保留未知状态，不伪造费用。
- **USG-010**：model_requests.agent_run_id 为可空外键，删除运行时 SET NULL，保留 Agent 标识与账单。agent_runs 不存请求 ID 数组或请求明细，仅保留运行信息与汇总；读取详情时关联返回请求 ID 和账单。运行状态与请求状态分离。
- **USG-011**：迁移逐条搬运旧 JSON 快照，保持原用量、金额及未知值，不重算历史价格；保留无明细运行的原合计。成功搬运后删除 model_usage_json。用量和诊断读取统一切换到账本，按请求时间建立索引。迁移失败整体回滚，重复启动不重复导入。实际用户数据库迁移前先备份并确认。
