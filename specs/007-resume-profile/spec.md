# 007 简历导入与候选人画像规格

> 状态：Implemented
> 依赖：001, 002, 003, 008

## 目标

从本地 PDF、DOCX 或 UTF-8 文本导入简历，确定性提取文字并优先按章节规则映射在线简历；只有结构无法可靠识别时才由 Agent 兜底，最终生成可检查、可修正、可锁定和可版本化的候选人画像。

## 功能需求

- **RES-001**：导入仅接受 PDF、DOCX、TXT，按内容而非扩展名校验媒体类型和大小上限。
- **RES-002**：原文件必须保存为 Artifact 并按 SHA-256 去重；重复导入返回已有文档。
- **RES-003**：文本提取必须记录 parser/version/status，失败时不得创建活动画像版本。
- **RES-004**：提取文本为空或低于质量阈值时必须提示需要可读文本，不静默调用 Agent 猜测。
- **RES-005**：ResumeProfileAgent 输出必须包含经历、教育、项目、技能、行业/职级事实及证据定位。
- **RES-006**：用户偏好必须与简历事实分离，包括目标地点、岗位方向、排除项和公司偏好。
- **RES-007**：用户可以修正字段并锁定 JSON Pointer；重解析不得覆盖锁定值或偏好。
- **RES-008**：每次提取或修正必须创建不可变 ProfileVersion，并保持一个当前版本；每个候选人画像只保留最新 5 个版本，淘汰旧版本时必须同时清理以其为输入的可重算匹配结果。
- **RES-009**：用户可查看原提取值、有效值、锁定路径、来源简历和 Agent 版本。
- **RES-010**：用户可显式删除简历和关联敏感数据；操作必须说明将影响的画像和匹配结果。
- **RES-011**：简历导入并生成画像后，用户可单独选择“项目经历”与“工作/实习经历”，请求 AI 按当前已确认的目标岗位润色对应的成果描述。
- **RES-012**：润色只能改写用户选中章节的描述文本，必须保持条目数量、公司/组织、职位、项目名称、角色和日期不变，不得编造原文不存在的技能、职责、指标或结果。
- **RES-013**：AI 润色结果必须先作为建议返回当前在线简历草稿；只有用户显式采用并保存后才创建新的画像版本，后台任务不得直接覆盖当前版本。
- **RES-014**：目标岗位为空、未选择润色章节或所选章节没有可润色内容时不得创建模型任务，并返回可操作的校验提示。
- **RES-015**：画像提取必须先使用确定性章节与条目规则；规则能完整识别已支持章节时直接创建画像版本，不得调用模型或创建 AgentRun。
- **RES-016**：规则提取必须采用保守门槛；章节不足、工作/项目条目头无法拆分、正文存在未解释结构或计数不闭合时必须整体回退 ResumeProfileAgent，不得静默保存残缺的规则结果。

## 质量与隐私需求

- **RES-Q01**：默认文件上限 10 MiB、提取文本上限可配置，超限在发送模型前失败。
- **RES-Q02**：普通日志不得包含简历正文、姓名、联系方式或文件内容。
- **RES-Q03**：发送给模型的内容必须是当前提取所需的最小文本，不附带文件路径或无关元数据。
- **RES-Q04**：解析和画像提取可取消、可重试且幂等。
- **RES-Q05**：润色模型输入只包含目标岗位和被选章节所需的最小结构化内容；普通任务列表、日志和错误信息不得暴露简历正文或润色结果。
- **RES-Q06**：规则判定只记录方法和非敏感原因码，不得把章节正文、联系方式或规则中间结果写入普通日志。

## 验收场景

1. 导入同一 PDF 两次只保留一份 Artifact 和 ResumeDocument。（RES-001,002）
2. 扫描图片 PDF 无文本时 parse 失败/needs_ocr，不创建画像。（RES-003,004）
3. 有效简历产生含证据的画像版本并成为 current。（RES-005,008）
4. 锁定地点偏好后导入新版简历，该值不变，新增技能可更新。（RES-006,007）
5. Agent 输出无证据技能时 Schema/应用规则拒绝该事实或标记 uncertain。（RES-005）
6. 删除命令先预览影响，确认后清理文档、画像敏感内容和推导结果。（RES-010）
7. 用户只选择项目经历时，后台结果仅包含与原项目逐项对应的描述建议，工作经历保持不变。（RES-011,012）
8. 润色任务完成后页面展示建议，未点击“应用到草稿”或未保存时当前画像版本不变。（RES-013）
9. 未确认目标岗位、未勾选章节或勾选的章节为空时，页面阻止提交并说明修正方式。（RES-014）
10. 润色任务执行期间用户仍可编辑；任务结果不会自动覆盖编辑中的草稿，重复提交被阻止且失败后可重试。（RES-013, RES-Q04）
11. 标题清晰、条目格式稳定的简历由规则直接填充在线简历，任务结果标记 `rules`，数据库没有新增 resume-profile AgentRun。（RES-015）
12. 缺少章节边界或经历条目格式含糊的简历不保存部分规则结果，而是完整回退 Agent 并标记 `llm`。（RES-016）
13. 连续创建超过 5 个画像版本后，历史查询只返回最新 5 个且版本号继续递增；最旧版本及其匹配结果不再保留。（RES-008）

## 未解决问题

无。OCR 不在首期范围，扫描 PDF 返回 `needs_ocr`。
