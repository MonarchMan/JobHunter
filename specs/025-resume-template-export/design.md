# 025 多模板简历制作与本地导出设计

> 状态：Implemented

## 边界

- `packages/resume-template` 保存公开投递 Schema、模板注册表和同源 React/HTML 渲染器，不访问数据库或浏览器。
- `packages/application` 编排草稿、头像、导出请求和任务，声明 Repository 端口。
- `packages/db` 实现草稿、导出请求和临时文件持久化。
- Web 只负责编辑、快照和交付；Worker 执行 `resume.export.pdf@v1` 并运行 Playwright。

## 数据模型

投递内容新增可选 `sectionVisibility` 记录章节是否已添加；旧草稿按已有内容推导，基本信息默认已添加。章节删除清空该章节字段、分栏行、隐藏块和排版设置，再记录 false；新增记录 true 并创建空白输入。专业技能新增可选 `professionalSkillBlocks`，兼容旧完整句子文本并保留退格后的普通段落。上述字段仅属于模板草稿。

进入制作页时将旧草稿推导结果固定为显式章节状态，避免用户清空文字后章节消失。编辑工具颜色从 Web 根令牌（action／action-soft／danger／danger-soft）传入 iframe，仅作用于悬浮按钮与块轮廓，不改写模板正文色板。

画布委托必须在 iframe 当前文档加载后注册，并在卸载时释放；结构按钮以完整属性描述操作，不依赖隐式焦点或按钮内文本。粉底悬浮工具高 24px，不占布局空间，键盘 Enter 不得被正文单行编辑拦截。列表退格在当前项内切换列表类型而非单纯减少缩进，使用浏览器编辑事务保留撤销栈。

`resume_template_drafts` 以 `(profile_id, template_key, template_version)` 唯一，保存源画像版本、公开内容 JSON、头像文件和 revision。`resume_export_requests` 保存一次不可变导出快照对应的输入 HTML、输出文件、任务状态和过期时间。源画像版本 ID 仅用于陈旧检测，不建立外键，以免阻止画像历史修剪。

## 导出数据流

1. Web 在导出前完成草稿保存，并把同源渲染器生成的 HTML 写入临时 `export` 文件。
2. HTML 请求直接交付该文件；PDF 请求入队，只把导出请求 ID 放入任务 payload。
3. Worker 读取 HTML，等待字体就绪，以 A4/背景图形生成 PDF，登记输出文件并完成任务。
4. Web 轮询请求状态，完成后交付文件；交付后清理输入和输出。清理任务兜底删除超过 24 小时的中转文件。

## 交互

制作页画布中的投递字段使用受控 `contenteditable` 文本块，点击后直接原位编辑；iframe 只向外层传递字段路径和值，外层仍通过草稿 API、Zod 和 revision 完成持久化。左栏提供章节索引和新增／删除按钮，未添加章节由 + 创建首个可编辑块。求职方向属于基本信息并紧邻模板姓名右侧，以灰蓝色粗体次标题显示，不生成独立 section。专业技能把换行分隔的完整事实句子渲染为一个可编辑无序列表。顶部对当前章节提供字号、字距和行高控制，控件组在桌面端与 A4 画布水平中心对齐；这些版本化排版值写入 `content_json.formatting` 并由同源渲染器消费。当前 section 的靛蓝轮廓和珊瑚色光标只存在于编辑模式。“预览”对当前本地输入取快照，并调用同源 HTML 渲染器的非交互模式；它不发起导出请求、不复用在线简历预览，且关闭后恢复触发按钮焦点。保存反馈为持久 `role=status`；冲突为 `role=alert` 并阻止导出。资料刷新使用应用自有确认对话框。

## 安全

编辑 iframe 采用 allow-same-origin allow-scripts 兼容 WebKit 对父页面事件回调的检查，同时由文档头首部 CSP 禁止文档脚本、网络、子框架、表单与 base，仅允许内置样式和 data 头像。只接受受控模板渲染结果，不接收任意 HTML；预览保持仅 allow-same-origin。此边界见 ADR-0022。

描述新增可选 `descriptionBlocks`（paragraph/bullet + text），旧草稿缺失时从 highlights 派生。普通章节新增可选 `textRows`，每组 1–3 栏，每栏为段落／列表数组，兼容纯文本；一栏为全宽内容块，没有单行限制。只持久化白名单结构与纯文本，不保存任意 HTML；两套模板及导出共用渲染。编辑中的 DOM 由浏览器维护，失焦仅提交快照；结构／排版变更才重新生成画布。

- 所有 mutation 使用现有 CSRF 双提交校验。
- HTML 对用户内容进行转义，内置模板不得插入任意 HTML。
- HTML 编辑脚本不访问网络，仅切换 contenteditable、保存当前文档和打印。
- 头像同时验证声明 MIME、文件签名、非空和大小，不接受 SVG。

## 响应式与打印

编辑态空白行内字段使用 inline-block 提供真实的点击盒，不只依赖占位伪元素绘制；悬停块层级高于仍保持焦点的相邻块，防止后一个角色／描述块遮挡前一个块的浮动按钮。浮动控件的鼠标命中与焦点切换须覆盖相邻小文本块，测试使用真实鼠标点击而非程序化聚焦。

内置渲染器按文本块输出悬浮按钮，通过 hover／focus-within 显示且绝对定位在右下方，不占排版空间。textRows.afterBlock 记录原始文本块锚点，确保新增行紧随被点击的块；hiddenBlocks 记录删除的内置块键，不影响同一经历的其它块和该锚点下的新增行。自定义行删除仍用数组过滤。未添加章节不渲染占位，左侧 + 提供首块入口，新增后聚焦新块。按钮不写入内容 JSON，非交互渲染不输出操作栏；取消外置列表切换按钮，键盘快捷键直接作用于编辑器内选区。

桌面为顶部排版工具 + 紧凑章节索引 + A4 画布；窄屏的排版工具和章节索引横向滚动，画布按容器缩放。文字编辑始终发生在画布内。打印渲染固定 A4，模板自己控制页边距和 `break-inside`，后台控件与编辑标记从打印 DOM 中排除。
