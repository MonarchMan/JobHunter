# 025 多模板简历制作与本地导出规格

> 状态：Implemented

## 目标

把当前在线简历作为可信资料源，生成可按内置模板独立修改、恢复并导出的投递稿。首版提供“简洁单页”和“标准单页”两套模板，支持本地 PDF 与自包含 HTML 导出。

## Requirements

### RTE-001 模板目录与入口

- 在线简历操作条必须提供模板选择和“导出”按钮。
- 内置模板必须有稳定 key、版本、名称、说明、缩略图和支持章节。
- 点击导出必须创建或恢复“个人资料 + 模板版本”唯一草稿并进入 `/resume-studio/[draftId]`。

### RTE-002 投递内容边界

- 草稿只能保存公开投递字段，不得包含证据、排除词、公司规模、管理经验等内部匹配数据。
- 模板修改不得反向创建个人资料版本，也不得影响其他模板草稿。
- 空章节必须在画布和导出中隐藏，但仍可从章节栏补充。

### RTE-003 制作页

- 制作页隐藏后台全局导航，保留返回、模板名称、保存状态、模板预览和导出操作；“预览”位于“导出 HTML”左侧。
- 模板预览必须使用当前模板与当前本地输入生成非交互快照，隐藏编辑标记和空白章节，不得复用在线简历预览。
- 主体显示完整 A4 实时画布；用户点击画布中的文字块后直接原位输入，不再打开结构化编辑对话框。左栏作为章节索引，未添加章节从左侧 + 创建首个输入块。当前章节标记不得进入导出文件。
- 顶部排版工具至少支持对当前章节调整字号、字距和行高，并可恢复模板默认值；排版设置随草稿保存并进入 HTML/PDF 导出。
- 桌面端排版控件组必须与 A4 简历画布水平中心对齐；当前章节说明与结构增删分列两侧，不得推动控件组偏离画布中心。
- 专业技能使用无序列表展示完整事实句子。简洁单页的求职方向紧邻姓名右侧，沿用参考模板的灰蓝色次标题层级，不单独成段或右对齐到画布边缘。
- 字段失焦自动保存；结构增删和头像变更立即保存。保存使用 revision 乐观并发，冲突不得静默覆盖。
- 当前个人资料产生新版本时必须提示，用户确认后才可用最新资料重建文本；头像保留。

- 工作／项目描述使用一个整体编辑区，允许普通段落与无序列表混排；回车续写列表，行首退格可取消圆点。保存、恢复、预览与导出保留段落类型。
- 普通章节可添加 1、2 或 3 栏的内容块组并删除指定组；1 栏占满章节宽度，每栏均允许多段文字和列表，没有单行限制。
- 字段失焦保存不得重载画布、丢失下一字段焦点；中文输入法确认不得被换行快捷键拦截。
- 就地操作以文本块为单位（标题行、角色、整段描述等），悬停或键盘聚焦显示小尺寸粉底 +1/+2/+3 和删除图标，绝对定位于右下角且不占排版空间。新增、删除必须支持鼠标和键盘，连续操作和保存后仍有效。控件、虚线框不进入预览或导出。
- 左侧每个章节提供新增与删除按钮，以“是否已添加”而非文字是否为空决定可用状态：已添加仅可删除，未添加仅可新增。未添加章节不出现在正文；新增后聚焦首个空白输入块，空白已添加章节刷新后仍保留。删除有内容的章节必须应用内确认，清除该章节模板内容和新增文本块，不修改在线简历。
- 列表项行首 Backspace 将当前项转换为普通段落并保留文字，其后 Enter 继续普通段落；不得影响其他列表项。项目、工作、专业技能与自定义块使用相同语义，并在保存、恢复和导出后保留。

### RTE-004 头像

- 头像属于模板草稿，不属于个人资料；只接受经文件签名验证的 JPEG/PNG，最大 5 MiB。
- 无头像时模板必须移除头像占位并回流布局。

### RTE-005 导出

- HTML 必须自包含且不请求外部资源，允许文字级编辑、再次保存和打印。
- PDF 必须由 Worker 使用本地 Playwright 生成；Web 进程不得启动 Chromium。
- PDF 请求返回 202 和任务状态地址；界面使用“生成/导出”措辞，不使用“下载”。
- 输出文件名使用“姓名-模板名-日期”并进行安全清理。

### RTE-006 生命周期与删除

- 导出中转文件成功交付后立即清理，异常或未取走文件最迟 24 小时清理。
- 删除源简历若导致个人资料删除，影响预览和执行必须包含草稿、头像和未过期导出文件。

## 验收标准

- Safari 与 Chromium 的编辑画布均可执行结构操作、失焦保存及章节定位；画布内容不得执行内联／外部脚本或加载外部资源。

- 鼠标可直接点击空白语言字段、开始／结束时间并输入；无需 Tab 绕行。文本块浮动操作应在指针从正文移入按钮时保持可点击。

1. 两套模板可从同一在线简历生成不同草稿并独立恢复。
2. 失焦保存、跨标签 revision 冲突、源版本过期提示和重建均可验证。
3. PDF 与 HTML 使用同一模板内容和版式规则，中文、分页、空章节和头像均正确。
4. 桌面与 390px 制作页均可完成键盘编辑和导出，满足 WCAG 2.2 AA 基线。
5. 制作页可在不导出的情况下预览当前模板效果，关闭后焦点返回“预览”按钮。
