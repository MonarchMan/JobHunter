# 021 个人面经文档导入规格

> 状态：Implemented

## 目标

让求职者把自己的面试经历以文件导入或在线填写的方式保存到本地。系统清洗并规范化问题—回答、元数据和备注，先生成可编辑草稿，只有用户确认后才进入“历史面经”。

## 首版假设

- 每次在线填写创建一段面试经历；一个导入文件可以包含一段或多段按标准标题分隔的经历。
- 支持 UTF-8 Markdown/TXT、PDF 和 DOCX，单文件最大 10 MiB；图片 OCR 不作为本规格门禁。
- `personal-experience@v1` Markdown 模板是首版标准格式，仓库保留可直接阅读的 `.md` 资产，Web 可以预览和下载同一内容。
- 首版规则解析标准模板及常见 `Q/A`、`问题/回答` 标记；结构不明确时保留原文和警告，交给用户在线修正，不调用模型猜测。
- 原文件 Artifact 与提取文本不可变；清洗后的草稿可以修订。接受草稿不会回写原文件。

## 非目标

- 不生成、补写或润色用户答案。
- 不把用户回答视为标准答案或其他项目的事实。
- 不在本阶段实现网友面经、外部 Agent 研究或问题聚类。
- 不承诺解析任意无结构散文；无法确认的段落必须保留为备注或警告。
- 不实现图片 OCR、批量文件队列和自动监听外部文件变化。

## 功能需求

- **EXP-001**：系统必须提供版本化标准 Markdown 模板，模板包含公司、岗位、阶段、日期、结果、难度、标签、问题、可选回答、复盘和过程备注，并能在 Web 查看和下载。
- **EXP-002**：用户必须可以上传 Markdown、TXT、PDF 或 DOCX；客户端和服务端都校验类型、非空及 10 MiB 上限。
- **EXP-003**：用户必须可以在线填写一段经历并动态增删问题；在线输入生成标准 Markdown Artifact 后进入与文件导入相同的解析链路。
- **EXP-004**：系统必须分别保存原始 Artifact、提取文本和规范化草稿；解析不得改写原文件或丢弃无法分类的文本。
- **EXP-005**：确定性清洗必须统一换行、结构标记的 Unicode 兼容形式、首尾空白、Q/A 前缀和空段落；问题与回答正文保留原始标点，同时保留它们在规范化文本中的字符范围。
- **EXP-006**：解析器必须支持问题无答案；不得根据常识补齐公司、岗位、答案、结果或日期。
- **EXP-007**：解析结果必须包含结构警告、未回答数量和未归类备注；警告不阻止用户进入在线校对。
- **EXP-008**：草稿页面必须允许修改元数据、问题、答案、复盘和备注，且以文档修订号进行冲突检查，避免静默覆盖较新修改。
- **EXP-009**：只有至少包含一个非空问题的草稿可以接受；接受后经历进入历史面经，原始证据和人工修订来源仍可追溯。
- **EXP-010**：历史面经必须按最近更新时间列出公司、岗位、阶段、日期、问题数和未回答数，并区分草稿与已接受状态。
- **EXP-011**：重复导入相同内容必须返回已有文档，不得重复创建经历；幂等键为内容哈希与解析器版本。
- **EXP-012**：用户必须可以删除个人面经文档；删除前展示派生经历、问题和独占 Artifact 数量，确认时重新校验影响哈希，共享 Artifact 不得误删。
- **EXP-013**：Web 必须提供上传、在线填写、草稿校对、接受、历史列表、模板预览/下载、错误恢复和窄屏操作。

## 质量与失败行为

- **EXP-Q01**：外部文件内容、表单输入和数据库 JSON 在边界使用运行时 Schema 校验。
- **EXP-Q02**：PDF/DOCX 文本提取、Artifact 文件写入发生在数据库事务外；数据库事务只提交短小结构化变更。
- **EXP-Q03**：模板、解析器和规范化规则必须有显式版本；修改规则不得静默重写已接受历史。
- **EXP-Q04**：页面表单必须使用应用内验证，保留失败输入，阻止重复提交，并满足 WCAG 2.2 AA。
- **EXP-Q05**：模板展示和规范化预览不得用不安全 HTML 渲染；原文件名不得被解释为本地路径。
- **EXP-Q06**：测试样本必须脱敏，普通 CI 不访问网络或真实模型。

## 验收场景

1. 用户下载标准模板，填写两个问题，其中一个无答案；上传后得到带两题和一条未回答提示的草稿，确认后出现在历史面经。（EXP-001,002,005,006,007,009,010）
2. 用户在线填写公司、岗位和两组问答；系统保存标准 Markdown Artifact，并进入同一个草稿校对页面。（EXP-003,004,013）
3. 用户上传带 `Q1/A1`、`问题/回答` 和普通备注的混合文本；系统清洗标记、保留顺序和字符证据，未归类内容留在备注中。（EXP-004,005,007）
4. 用户修改草稿后，另一窗口已保存更新；旧修订保存被拒绝且页面保留输入并提示刷新。（EXP-008, EXP-Q04）
5. 用户导入同一文件两次，只返回原草稿；更换解析器版本才允许产生新的解析结果。（EXP-011, EXP-Q03）
6. 用户尝试接受没有问题的草稿，系统显示可修正错误，不生成历史面经。（EXP-006,009）
7. 删除预览后文档发生变化，旧影响哈希失效；重新预览确认后删除派生数据和独占 Artifact，不影响共享文件。（EXP-012）
8. 在 390px 窄屏上，模板、上传、在线填写和草稿操作均可用，键盘焦点与错误说明可见。（EXP-013, EXP-Q04）

## 未解决问题

无。
