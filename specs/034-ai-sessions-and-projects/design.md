# 034 数据与执行设计

> 状态：Implemented

ai_sessions 保存 id/type/title/created_at/updated_at；ai_messages 保存 id/session_id/role/content/sequence/status/created_at/updated_at，session_id/sequence 唯一。可选画像和项目关系归 ai_session_metadata，应用层校验通用 value 引用并在删除时清理。会话读取当前画像项目，不固定历史画像版本。

画像项目身份由系统分配，模型提取不得任意覆盖稳定 ID 和本地路径；候选提取结果与已确认画像分离，应用时重验基线。新会话不创建档案、快照、知识项或覆盖状态。旧回答仅迁移最新内容，旧问题和已生成回复保留，不把旧修订转存另一张表。

第二阶段实施细化：首次提取可建立当前画像；再次提取写入 profile_versions 的候选版本（is_candidate=1、is_current=0），base_version_id 记录提取基线。所有画像属性直接保存到对应列，候选与生效版本均不保存整份 JSON 副本。确认时按用户选择的一级字段生成新生效版本，检查基线仍为当前版本；过期候选要求重新提取。项目编辑与排序使用稳定 id，模型输出只提供项目事实，由系统匹配已有身份并保留 local_path。

研究任务 private_state 保存岗位 Brief、执行模式和阶段检查点；精确输出路径由数据根目录与任务 ID 确定，避免移动数据目录后保留失效绝对路径，public_state 只保存脱敏进度、错误及结果摘要；模型请求保存调用诊断。指定路径读取须限制大小、验证普通文件并防止目录逃逸和符号链接替换，模型与文件 I/O 不放入数据库事务。结果校验与导入共用同一用例，最终事务检查任务执行权及导入幂等。Agent 权限仅开放指定结果输出，不能开放数据库或整个数据目录。

中央服务实施见 003 与 ADR-0062。旧业务专用表的引用、清理和页面一起迁移，不以长期转发表掩盖旧实现。已获用户本轮迁移授权；执行前完成测试库演练和一致性备份，停止所有旧写入进程，失败保留备份并不启动不兼容服务。

第二阶段的会话替换同时删除旧回答修订、二次知识与覆盖状态，停用旧项目练习写入口；第三阶段已移除项目档案和材料实现，并将研究迁入阶段任务。AI 回复统一发布 ai.reply 任务；生成输入包括当前可选项目事实与本会话当前消息，不读取 local_path。Agent 禁用结果缓存和输出副本，model_requests 仅关联消息并保存调用诊断。用户编辑取消未完成回复，结果提交时再次校验输入。

## 第三阶段落地约束

项目位置由当前画像的 project.local_path 编辑和清空；系统只存位置，不上传、复制或自动读取目录。旧档案、材料和备忘录入口及实现删除。

研究以 interview.experience-research 父任务持有 brief 和导入检查点；创建后等待外部交付，系统执行作为关联子任务。等待文件的父任务不占执行器、不靠轮询调度。校验导入完成即成功，候选审核独立于执行成功。指定路径按数据根目录和任务 ID 生成，仅允许普通 JSON 文件；重复检查同一内容不重建候选。任务清理通过 SET NULL 解除来源关联，保留面经、问题和审核结果。
