# 034 通用 AI 会话、画像与本地项目

> 状态：Implemented
> 依赖：003, 007, 008, 020, 023, 024, 033

## 已确认范围

本规格替代旧面试设计中的项目档案快照、回答修订、项目知识提取、上传项目材料及人工上传研究包方案。实现完成前旧表描述只用于解释迁移来源，不代表新的目标约束。

- **AIS-001**：drill_sessions、drill_turns 转为 ai_sessions、ai_messages；会话以 type 区分模拟面试和日常对话，不设置暂停或完成状态，不新增 context_json 或消息 metadata_json。
- **AIS-002**：ai_session_metadata 使用独立 id、session_id 外键、name、value、created_at、updated_at，唯一约束为 session_id/name；关联画像或项目失效时清除相应关联，消息与继续对话能力保留。
- **AIS-003**：消息包含 role、content、sequence、生成状态及时间，修改回答覆盖原值，不保留回答修订或通过模型请求正文间接保存旧答案；已有后续回复不自动改写。生成期间相关输入变化必须拒绝迟到结果。
- **AIS-004**：model_requests 可空关联 assistant 消息，支持一次消息多次模型请求；消息删除后解除关联，非对话调用不强制创建消息。
- **AIS-005**：画像一级属性展开为列，嵌套集合使用各自 JSON 列，不保留 effective_json 副本。删除 extracted_json 与 locked_paths_json，重新提取必须预览差异并经用户选择确认，提交检查画像并发修改。
- **AIS-006**：画像 projects 中使用稳定 id 与可空 local_path；编辑、排序保留身份。删除 project_dossiers、项目快照、project_knowledge_items、回答修订及持久化覆盖进度，不再上传或管理项目材料。
- **AIS-007**：记录本地项目位置不自动扫描文件或装配源码上下文。路径失效不阻断对话；模型上下文管理另行设计，本次不预留摘要或上下文存储字段。
- **AIS-008**：删除 experience_research_requests，由分阶段 tasks 承接研究；预留本地 JSON 结果位置，外部 Agent 写临时文件后原子改名，系统在 Agent 退出或用户检查结果时校验并导入，重复检查不得重复导入。
- **AIS-009**：候选面经以可空 research_task_id 关联任务；导入成功任务即完成，审核保存在面经业务记录。清理任务不删除候选来源与审核结果。
- **AIS-010**：按中央服务、画像与会话、项目与研究三个阶段实现；全部验证后备份并迁移真实数据。迁移验证行数、消息顺序、保留内容和外键完整性；完成后报告模型上下文实际来源、装配、边界和未实现项，不将目标当成已实现。

## 验收

历史每个问题与最新回答迁为独立消息且排序稳定；项目删除和无效路径下仍可对话；用户修改与模型回复竞争不能覆盖新内容；重新提取不自动覆盖画像；外部 JSON 不完整、无效或重复检查均不产生重复面经。文件、事件与通用系统支撑的现有数据不得误删。
