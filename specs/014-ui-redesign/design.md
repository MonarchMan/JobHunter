## 运行时结构

不引入第三方主题或成套 UI 框架。现有 Next.js App Router 和 Server Components 保持不变；对应用必须拥有弹层几何和键盘语义的复合控件，可引入聚焦的无样式可访问性原语，外观仍只由 JobHunter 令牌和 CSS Modules 拥有。

```text
DESIGN.md（意图与规范值）
  ↔ apps/web/app/styles/tokens.css（运行时唯一令牌源）
      → apps/web/app/styles.css（全局装配入口）
          → styles/foundations.css、product-shell.css（迁移期跨路由基础与壳层）
      → 路由或组件旁的 *.module.css（局部样式）
```

`styles/tokens.css` 中的 `:root` 作为唯一运行时令牌源；`styles.css` 只保留有序 `@import`。全局分片只承载基础元素、应用壳层与跨路由共享视觉；边界清晰的页面和组件使用就近 CSS Modules。所有样式只能消费语义变量，不新增独立主题表。`DESIGN.md` 镜像同一组已批准值，用设计 lint 和颜色搜索防止漂移。

迁移按完整页面或共享组件切片推进：先原样拆分并验证全局级联，再将单一路由或单一组件拥有的选择器移动到同目录 CSS Module，最后删除对应全局规则。设置页是首个路由样板；应用壳层、主导航与工作台已完成就近模块化并移除 `dashboard.css`；职位列表的筛选、结果工具栏、选择表格、移动卡片、评分操作与图标已归入页面或组件模块并移除 `jobs.css`，通用全元素表格规则也已由职位表格和共享诊断表格模块分别接管；职位详情的标题、操作区、详情网格、修订时间线、匹配证据与建议样式已归入路由模块；个人资料的页面布局、导入、在线简历、维护和删除样式已归入路由内模块并移除 `profile.css`，同时删除无消费者的旧只读简历选择器；招聘来源页、分类导航、公司来源卡和操作区已完成模块化并移除 `sources.css`，公司 Logo 的来源标题尺寸由显式 `source-heading` 业务变体拥有，不再依赖全局祖先选择器；来源同步复用同一客户端操作组件，卡片级与页面级按钮均使用共享线性刷新图标、固定尺寸 busy 状态和可聚焦提示，页面级按钮在分类工具栏右侧批量为全部启用来源入队；任务筛选、诊断表格、移动卡片、自动刷新、任务操作和诊断弹窗已归入任务路由及共享诊断表格模块，后台任务列表使用路由业务类统一水平、垂直居中，Agent 运行详情复用同一表格模块并在路由内约束长技术指纹换行；`CompanyCombobox`、`CompanyLogo`、`Pagination`、`TruncatedText`、`PageHeader`、`MetricCard`、`DashboardHero` 与 `DashboardSteps` 是首批共享组件样板。页面级迁移已完成，全局分片仅保留基础元素、壳层和具有多个跨路由消费者的共享语义类。

## 页面壳层

- 桌面端使用 224px 侧边导航和自适应内容区。
- 1024px 以下转换为顶部品牌栏与可横向访问的紧凑导航；600px 以下优先显示核心入口，并保持所有入口可达。
- 首页使用品牌型 Hero；其他页面使用紧凑工作标题。
- 表格页、详情页和表单页分别使用宽、标准、窄内容密度。

## 视觉与动效

品牌色使用档案靛蓝，珊瑚色只标记下一步行动。成功使用蓝青色并配合图标/文字，避免重新引入绿色。动效令牌为 120ms、180ms、260ms，使用统一 ease-out/standard 曲线。壳层不重复入场，局部内容只在状态变化时动画。

页面画布使用淡靛蓝底色与白色工作面板形成层次；共享 `Icon` 组件提供 1.75px 线性 SVG 图标。职位评分使用 portal 挂载的固定定位 popover，桌面优先出现在按钮右侧、空间不足时翻转，避免被表格滚动容器裁切。表格长文本使用共享 `TruncatedText`，悬浮和键盘聚焦均显示完整值。

公司筛选使用共享 `CompanyCombobox` authored listbox，不再依赖浏览器 `datalist`。选项数据按公司名去重，输入框与弹层共用宽度和圆角令牌；组合框保留自由文本筛选能力。`CompanyLogo` 从 `/assets/company-logos/` 读取本地资源并提供首字回退。个人资料增加只读结构化简历摘要，开发者 JSON 降为次级详情；`015-resume-ocr` 将原禁用 OCR 入口替换为同一上传控件支持的 JPEG/PNG 后台流程。

职位筛选与任务筛选中的单选、个人资料页的全部单选统一使用共享 `SelectField` authored listbox；它同时支持服务端表单默认值和客户端受控草稿，通过 portal 挂载，使用 popper 定位在触发框下方，与触发框等宽、内部滚动并在空间不足时碰撞调整。方向键、Enter/Space、Escape、字符快速定位、焦点恢复和可访问状态由无样式原语拥有；触发框、弹层和选项外观由共享 CSS Module 消费现有令牌。来源设置中已明确接受平台弹层的低风险单选仍保留原生变体。任务详情中的职位详情同步批次直接以细分割线承接通用任务事实，不增加重复章节标题。

个人资料参考主流校园招聘简历编辑器的纵向编辑节奏，但沿用 JobHunter 档案靛蓝视觉：导入区是入口，解析完整度和求职意向构成摘要，教育、工作、项目使用带编号的时间线条目，技能与偏好使用紧凑标签。桌面端章节导航为粘性目录，窄屏转换为横向滚动目录；锚点滚动尊重固定导航和减少动态效果。领域模型未覆盖的姓名、电话、作品附件等仅记录为未来扩展，不显示虚构资料。

结构化简历升级为单一长表单，由 `StructuredResumeEditor` 统一拥有草稿状态、校验、保存与预览。保存通过 `replace` mutation 一次写入完整 `CandidateProfileData` 并生成单一版本，沿用 `expectedVersionId` 乐观并发。预览通过 portal 模态弹窗显示当前未保存草稿，弹窗体内部滚动、页脚保持可达、Escape 关闭并恢复触发按钮焦点；渲染器对空字段和空章节做统一过滤。

章节标题本身已经表达结构，不再叠加 `RESUME SECTION` 眉题。预览与关闭预览使用中性 outline/soft hover，主保存按钮独占实心靛蓝强调。在线简历日期选择保留原生 `input[type=date]` 作为交互层，接受 Edge/Chrome 的平台日历、月份/年份切换和键盘行为；起止时间在其上使用只读的应用 ISO 表面固定显示 `YYYY-MM-DD`，不再依赖系统区域格式决定可见顺序；领域层继续保存 ISO 日期字符串。

整份简历提交前由编辑器统一清理重复条目：原生日期控件显示空值所需的空字符串恢复为领域模型使用的 `null`；完全空白的条目移除；仍有日期、描述、组织或其他内容但领域必填名称为空的条目，恢复该类型新增条目已使用的“待填写”名称。这样既保留用户输入，也保证客户端提交体满足画像边界 Schema，避免整份保存被笼统 400 拒绝。

经历类起止日期由共享 `DateRangeField` 作为一个语义组呈现：可见界面只保留“起止时间”标题和两个日期控件，开始/结束含义通过原生输入框 `aria-label` 提供；透明原生日期输入覆盖应用 ISO 表面，负责弹出平台日历，表面只读取标准值并固定显示 `YYYY-MM-DD`。组本身在桌面双列表单中只占一列（半行），内部日期等宽同排，窄屏随表单切换为整行。标题与普通字段标签共享正常字重、行高及 `0.45rem` 标签间距，控件顶边对齐。载入旧的 `YYYY-MM` 值时补齐为当月首日，使教育、工作和项目的编辑与预览均使用完整日期。专业技能使用单一长文本字段，底层保留解析得到的结构化技能供匹配继续使用。章节字号提升一级，hover 与 `:focus-within` 只改变浅色背景和边框；预览按钮保持纯文字。

在线简历章节目录由编辑器本身拥有。宽屏时编辑正文与目录组成两列，目录在右侧使用 `position: sticky` 跟随视口但止于编辑器边界；目录可收起为仍可聚焦的“目录”恢复入口。滚动联动通过被 `requestAnimationFrame` 节流的被动滚动监听读取章节实时位置，以当前断点的 `scroll-margin-top` 作为顶部判定线，选择最后一个已经到达该线的章节；判定线不得按视口高度比例下移，也不得缓存只在阈值交叉时更新的观察器坐标，避免高视口或浏览器缩放时提前选中短章节的下一项。联动只更新当前章节状态，不改写浏览历史；目录点击由应用同步写入可分享的 hash、调用 `scrollIntoView` 并更新当前项，避免 Safari 原生锚点在点击回调和滚动事件之后才定位而留下错误高亮。当前项使用 `aria-current="location"`、浅靛蓝背景和 3px 珊瑚色决策光标。1100px 以下或高缩放重排时恢复为顶部横向 sticky 目录，保持自然文档滚动和底部保存栏可达。

AI 润色入口使用在线简历工作台内的紧凑工具条变体：白色静态面板沿用细边框和 3px 珊瑚色决策光标，不再铺满主色软背景；标题、目标岗位与“不新增事实”边界组成首行，润色范围与唯一主操作组成第二行。原生复选框继续拥有键盘和无障碍语义，但组件局部明确覆盖全局输入框的宽度、最小高度与内边距，避免浏览器切页或样式重算后把标签挤成竖排。建议结果仅在生成后展开，窄屏按信息顺序换行且不改变操作能力。

职位列表的职位名称以 `WebJobListItem.detailUrl` 为唯一导航目标，桌面表格与移动卡片均在安全新标签页打开官网详情。站内详情继续保留为诊断能力，但数据库适配器在边界处把领域层数组式 `ChangedField[]` 转换为 Web 契约需要的字段对象，同时继续接受早期对象式 change set；首版 `[]` 归一化为空对象。

## 交互保持

- 筛选、排序和分页继续使用 URL 参数。
- 列表继续使用服务端数字分页。
- 耗时操作继续只入队，由页面刷新状态。
- 删除继续使用现有影响预览与应用内二次确认。
- 单选控件按几何所有权选择变体：接受系统弹出层时使用原生 `select`，需要稳定宽度、边框和定位时使用共享 authored `SelectField`。
