# 014 全系统 UI 重设计规格

> 状态：In Progress
> 里程碑：R2
> 依赖：011

## 目标

在不改变既有业务流程、数据生命周期和安全边界的前提下，将 Web 管理台统一改造为以档案靛蓝为主色、结构紧凑、反馈连续、支持桌面与移动端的个人求职工作台。

## 非目标

- 不修改领域模型、任务状态机、来源同步策略或删除语义。
- 不引入第三方主题或成套 UI 框架、不引入远程字体依赖；允许为复合控件引入无视觉绑定的可访问性原语。
- 不新增暗色主题、多用户权限或移动原生应用。
- 不使用持续循环的装饰动画。

## 功能需求

- **UIR-001**：全局必须使用统一的非绿色语义色令牌；品牌主色为档案靛蓝，成功状态也不得依赖绿色。
- **UIR-002**：桌面端必须提供稳定的侧边导航和内容工作区；窄屏必须转换为不拥挤的移动导航。
- **UIR-003**：工作页面标题、容器宽度和留白必须根据表格、详情、表单三类内容使用一致布局契约。
- **UIR-004**：按钮、链接、表单控件、状态标签、表格行和弹层必须覆盖 hover、focus、active、disabled、busy 与错误状态。
- **UIR-005**：职位列表必须突出职位、公司地点、匹配和官网操作；移动端必须使用独立的记录卡布局。
- **UIR-006**：来源页面必须将摘要与低频设置分层，避免默认展开全部运行和计划信息。
- **UIR-007**：任务与 Agent 运行页面必须优先显示用户语言，技术标识降级为辅助信息，并保持筛选与分页状态。
- **UIR-008**：个人资料、设置、空状态、404 和路由错误页面必须复用全局视觉、反馈和导航语言。
- **UIR-009**：界面动效必须使用统一时长与缓动，只解释进入、展开、更新和完成；减少动态效果时必须关闭非必要动画。
- **UIR-010**：后台刷新不得造成整页闪烁、控制尺寸变化或滚动位置跳动。
- **UIR-011**：页面背景与工作面板必须形成稳定层次，并以统一线性图标增强导航和操作识别，不得用 emoji 充当产品图标。
- **UIR-012**：职位评分选项必须在触发按钮右侧以不改变表格布局的浮层展示；“官网投递”和“评分”必须同排。
- **UIR-013**：职位表格必须将公司与地点拆为独立列；没有部门或职位类别时不得显示占位文案“类别未注明”。
- **UIR-014**：表格长文本必须单行截断并显示省略号，鼠标悬浮或键盘聚焦时必须显示完整内容浮层，地点字段必须覆盖该行为。
- **UIR-015**：公司筛选必须使用应用自有的可访问组合框，去重展示公司并统一弹层宽度、滚动、键盘选择和清除行为。
- **UIR-016**：已知公司必须使用本地 Logo 资源增强识别，图片缺失时必须显示稳定的文字回退且不能阻塞内容。
- **UIR-017**：个人资料必须用结构化分区展示简历画像；导入卡片必须说明 PDF/DOCX 自动解析与 JPEG/PNG 后台 OCR 流程，能力状态必须与实际可用范围一致。
- **UIR-018**：个人资料必须以长简历编辑场景组织为可定位章节，教育、工作和项目采用重复条目时间线；页面必须补充求职意向、偏好与解析完整度，同时不得为领域模型尚未保存的基础身份字段伪造数据。
- **UIR-019**：结构化简历的每个章节必须支持手动编辑，并以一次显式保存生成一个画像版本；必须补齐基本信息、作品、竞赛、证书、语言能力和自我评价章节。
- **UIR-020**：结构化简历卡片底部必须提供“保存”和“预览”操作；预览使用应用内可滚动模态弹窗，读取当前表单值并隐藏所有未填写章节，关闭后恢复触发按钮焦点。
- **UIR-021**：在线简历章节不得重复显示无信息价值的英文眉题；预览和关闭预览必须保持中性次级按钮配色，hover 时不得继承主保存按钮背景且文字对比必须清晰。
- **UIR-022**：教育、工作、项目、竞赛与证书的时间字段必须使用日历式日期输入，并在支持的 Edge/Chrome 平台提供月份与年份快速切换；起止时间控件必须使用应用拥有的 ISO 显示层固定呈现 `年-月-日`，不得依赖操作系统决定可见字段顺序。
- **UIR-023**：教育、工作与项目的开始/结束日期必须合并为同一“起止时间”字段组；可见界面只保留“起止时间”标题和两个日期控件，不显示“开始日期”“结束日期”或预计日期提示，但控件必须保留可访问名称；标题必须与普通字段标签使用相同正常字重、行高和标签—控件间距，日期控件必须与同行普通输入框水平对齐；该组在桌面端只占表单栅格的一列（半行，外宽与“学校”等字段一致），内部两个输入等宽，所有新旧起止日期均以完整 `年-月-日` 格式呈现；窄屏时随单列栅格扩展为整行。
- **UIR-024**：项目详情字段必须命名为“项目描述”；“技能与领域”必须改为单一“专业技能”文本区，不再把技能拆为大量重复条目；预览操作不得显示图标。
- **UIR-025**：在线简历字段和说明文字必须提高可读字号；鼠标悬停或键盘焦点进入某一章节时，章节背景必须使用轻量状态色反馈且不能造成布局位移。
- **UIR-026**：职位列表中的职位名称必须直接、安全地打开该职位的官网详情 URL，不得默认进入站内诊断详情；站内职位详情读取历史修订时必须兼容领域层写入的数组式 change set 与已有对象式数据，不能因首版空数组导致整页崩溃。
- **UIR-027**：来源卡片的同步操作必须使用具有可访问名称和悬浮/聚焦提示的刷新图标按钮；官网来源页必须在分类切换栏右侧提供同一水平线上的“全部同步”刷新按钮，并复用单来源同步的幂等、忙碌和内联反馈契约。
- **UIR-028**：在线简历保存必须清理重复条目的空白值；原生日期输入使用的空字符串必须恢复为 `null`，仍包含日期、描述或其他内容但名称被清空的工作、项目、作品、竞赛、证书和语言条目必须恢复对应“待填写”名称后再提交，不得以无字段提示的 400 阻断整份简历保存。
- **UIR-029**：在线简历章节目录必须在宽屏编辑区右侧以可收起的 sticky 导航呈现，并根据各章节相对视口的实时位置突出当前章节；点击目录项时必须由应用同步完成 hash、滚动定位与当前项更新，使页面顶部实际显示的章节与当前项在 Safari 等浏览器中一致，不得误选相邻的下一章节。当前项必须同时提供 `aria-current`、浅靛蓝背景和珊瑚色决策光标。收起后必须保留可恢复入口；窄屏和高缩放布局必须转为不压缩表单的顶部横向 sticky 导航。
- **UIR-030**：职位筛选的招聘类别、职位类别、状态、排序、个人资料版本，以及个人资料页标题区的“选择画像”必须使用应用拥有几何的共享单选控件；弹层必须从触发框下方展开、与触发框等宽且不覆盖触发框，并支持方向键、Enter/Space、Escape、字符快速定位、选中状态和视口边缘碰撞处理。
- **UIR-031**：个人资料页中的所有单选下拉必须使用共享 authored `SelectField`，包括在线简历的目标岗位、接受远程、管理经验，以及高级维护区的接受远程；共享组件必须同时支持表单默认值和受控草稿状态，不得回退为平台原生弹层。
- **UIR-035**：任务页的状态和类型筛选必须复用共享 authored `SelectField` 并保持 URL 表单提交；职位详情同步批次在任务详情中使用分割线与上方通用任务事实区分，不显示重复的批次标题。
- **UIR-036**：中文页面标题和分区标题不得附带纯装饰性的英文眉题或英文副标题；公司名、文件格式、协议名和诊断标识等具有实际含义的内容不受此限制。
- **UIR-037**：面试准备入口必须把简历项目队列与已有准备档案组织为同一档案工作台；桌面端使用主次明确的双栏，窄屏按自然阅读顺序转为单栏。项目必须使用连续档案行而非并排卡片，长项目描述不得把主要操作推离当前视野；珊瑚色决策光标只标记可继续的真实准备进度，不得装饰所有档案或当前分区导航。
- **UIR-032**：在线简历的 AI 润色入口必须使用紧凑的工具条式面板，标题、目标岗位、安全边界、可选范围与生成操作在桌面端不得产生无意义的大面积留白；复选框必须覆盖全局表单尺寸并保持中文标签水平排版，窄屏时操作完整可达且页面不得横向溢出。
- **UIR-033**：来源公司卡片标题必须使用不依赖字体基线的两层布局，并统一 Logo、原生渠道选择和操作控件的几何；公司综合健康不得继续占用独立大卡片，必须由细状态边框、3px 内侧色轨、浅色光晕及带文字状态点共同表达，且健康色仅作为来源运行语义，不得扩散为品牌色。
- **UIR-034**：来源公司卡片不得使用固定最小内容高度或嵌套大号统计卡制造空白；公司总览必须使用紧凑分隔式指标条，宽卡四项同排、窄卡两列，并压缩标题、控制区和内容区留白，同时保留 44px 核心操作热区和完整响应式能力。

## 质量需求

- **UIR-Q01**：达到 WCAG 2.2 AA 基线，支持键盘、可见焦点、语义 HTML 与非颜色状态表达。
- **UIR-Q02**：支持 1280px 以上桌面工作流、768px 主要操作和 390px 核心工作流。
- **UIR-Q03**：常规动效不超过 320ms，优先使用 `transform` 与 `opacity`，并支持 `prefers-reduced-motion`。
- **UIR-Q04**：运行时令牌必须由 `apps/web/app/styles/tokens.css` 单一映射，`apps/web/app/styles.css` 只作为全局样式装配入口；不得新增页面级颜色或动效常量。
- **UIR-Q05**：实现必须通过格式检查、类型检查、Web 测试、构建和浏览器无障碍验证。
- **UIR-Q06**：全局 CSS 只承载令牌、基础元素、应用壳层和跨路由共享视觉；边界清晰的页面与组件样式必须逐步迁移为就近放置的 CSS Modules，迁移期间不得改变既有级联结果。

## 验收场景

1. 打开任意主要页面，不再出现绿色品牌或成功状态，焦点和状态仍清晰可辨。（UIR-001,004）
2. 在 1280px 桌面端切换六个主要区域，侧边导航稳定且工作区宽度与内容类型匹配。（UIR-002,003）
3. 在 390px 视口浏览职位、来源和任务，不出现六项文字导航挤压，核心操作无需横向页面滚动。（UIR-002,005–007）
4. 打开筛选、详情、抽屉或对话框，动效连续且焦点行为正确；启用减少动态效果后仍可完成操作。（UIR-004,009, UIR-Q01,03）
5. 后台任务刷新时，页面壳层、滚动位置和按钮尺寸保持稳定。（UIR-010）
6. 404、空数据、失败和加载状态使用同一视觉与用户语言，并给出恢复路径。（UIR-008）
7. 在职位表格展开评分，选项浮层出现在触发按钮右侧，操作按钮不换行且表格列不发生位移。（UIR-012）
8. 公司和地点分别成列；长地点显示省略号，悬浮或聚焦后可读取完整地点。（UIR-013、UIR-014）
9. 公司组合框只显示去重后的公司，弹层与输入框同宽，可用方向键、Enter、Escape 和清除按钮操作。（UIR-015）
10. 职位和来源使用本地公司 Logo；个人资料按求职方向、教育、经历、项目、技能和偏好分区，并明确 PDF/DOCX 自动解析与 JPEG/PNG 后台 OCR 的支持范围。（UIR-016、UIR-017）
11. 个人资料长页面可通过章节导航直达内容；教育、工作、项目清楚呈现时间范围，缺失信息提供明确的补充提示而不是虚构值。（UIR-018）
12. 编辑任意章节后点击保存，只产生一个新画像版本；并发冲突不会覆盖新版本，输入仍保留在页面。（UIR-019）
13. 未保存时点击预览，可在可滚动弹窗中核对当前内容；空的作品、竞赛、证书、语言或评价章节不出现。（UIR-020）
14. 各章节只显示中文标题；悬停“预览”或“关闭预览”时仍是清晰可读的中性按钮，不与“保存简历”混淆。（UIR-021）
15. 点击任意经历、竞赛或证书日期字段，可打开本地化日历并切换月份和年份；起止日期在任何 Windows 区域格式下都由应用表面显示为 `YYYY-MM-DD`。（UIR-022）
16. 教育、工作和项目中，整个起止时间组在桌面端只占半行并与普通字段等宽；可见内容只有“起止时间”和两个同排等宽的完整日期控件，标题不加粗，标题与控件间距及控件顶边和同行普通字段一致；窄屏时整组扩为一行，屏幕阅读器仍可区分开始与结束日期。（UIR-023）
17. 在线简历只显示一个“专业技能”多行文本框，项目使用“项目描述”标签，预览按钮不包含图标。（UIR-024）
18. 字段字号清晰，鼠标悬停或键盘进入章节时出现浅色背景反馈，不改变章节尺寸。（UIR-025）
19. 点击桌面表格或移动卡片中的职位名称，会在安全的新标签页打开官网详情；即使数据库中的首版修订 change set 为 `[]`，站内详情服务也能正常返回。（UIR-026）
20. 悬浮或聚焦来源卡片右上角的刷新图标时显示“立即同步”；官网来源分类栏右侧的“全部同步”刷新按钮与分类栏垂直居中，并一次为所有启用官网来源创建幂等同步任务。（UIR-027）
21. 教育、工作或项目日期留空，或清空工作、项目、证书等重复条目的必填名称但保留其他内容后，仍可一次保存整份简历；空日期保存为 `null`，缺失名称使用对应“待填写”名称。（UIR-028）
22. 在桌面滚动在线简历时，右侧章节目录保持可见并自动突出当前章节；点击“作品”等目录项后，页面顶部和 `aria-current` 必须同时指向“作品”，不得提前突出“竞赛”。目录可收起和恢复，键盘可读当前项。窄屏时目录回到表单顶部横向显示且不造成页面横向溢出。（UIR-029）
23. 在 macOS/Safari 和 Chromium 打开职位筛选的任一单选或个人资料页的“选择画像”时，应用弹层从触发框下方出现，宽度误差不超过 1px，不覆盖触发框；键盘可完成展开、游走、选择和关闭，提交后 URL 保留对应选择。（UIR-030）
24. 个人资料页不存在原生 `select`；在线简历和高级维护中的四个单选均使用共享 authored 弹层，选择后立即更新各自草稿值，并保持键盘操作、等宽定位和保存语义。（UIR-031）
25. 全局样式可按职责独立维护，设置等已迁移页面使用就近 CSS Module；页面切换、响应式布局和交互状态与迁移前一致。（UIR-Q06）
26. 在线简历的 AI 润色入口在桌面端以紧凑两行工具条呈现，复选框和中文标签不被全局输入框样式拉伸或挤成竖排；选中态、不可用说明、生成反馈和结果预览仍完整，390px 下无横向页面滚动。（UIR-032）
27. 来源公司卡片在 Windows Chromium/Edge 中使用两层标题布局，Logo、标题、渠道和操作控件不依赖文字基线对齐；综合状态不再占用独立大卡片，而由 1px 状态边框、3px 内侧色轨、浅色光晕及带文字圆点共同表达，健康、退化、异常分别为绿、黄、红且不只依赖颜色。（UIR-033）
28. 来源公司总览不设置人为最小高度，四项指标共享一个分隔式数据条；宽卡四项同排，常规双列卡与窄屏回落为两列，卡片内容随真实信息自然收拢且同步按钮热区不低于 44px。（UIR-034）
29. 任务页的状态和类型筛选使用与职位筛选一致的共享 authored 下拉；职位详情批次弹窗在一条分割线后直接展示批次事实，不出现“职位详情同步批次”重复标题。（UIR-035）
30. 工作台、列表、详情、表单、错误页和面试准备页面的中文标题均不再叠加装饰性英文标题；职位公司名和必要技术术语仍正常显示。（UIR-036）
31. 面试准备入口在宽屏显示项目主队列和档案恢复栏，在 390px 窄屏转为无横向溢出的自然单栏；项目摘要限制行数，操作保持可见，只有进行中的档案显示决策光标。（UIR-037）

## 未解决问题

无。
