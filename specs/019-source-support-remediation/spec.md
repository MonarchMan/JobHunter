# 019 非 supported 官网渠道闭环规格

> 状态：In Progress
> 依赖：004, 005, 006, 016, 017, 018

## 目标

将当前 9 个 `experimental` 和 20 个 `blocked` 逻辑渠道逐项闭环为可默认运行的 `supported`，使 15 家目标公司的实习、校招、社招 45 个逻辑渠道均具备真实、可审计、失败隔离的官方职位采集能力。

## 需求

- **SSR-001**：为 29 个非 supported 逻辑渠道维护逐项证据，至少包含官方入口、物理来源、协议、稳定职位 ID、分页、详情、招聘类别、访问限制和最近在线门禁结果。
- **SSR-002**：渠道晋级必须取得至少一个 required 物理来源的真实职位，并以 2–3 页定向 smoke 覆盖首页与末页（可选中间页），验证样本内稳定且唯一的 external ID、岗位级官方 URL、字段归一化和分页边界；不得只修改 catalog 状态。
- **SSR-003**：不得登录、复用候选人 Cookie、绕过验证码或使用非官方聚合数据。允许对公开官网 JavaScript 做隔离的静态分析和匿名可重复性 Spike，以判断官网签名模块能否作为原样依赖运行；Spike 不得伪造浏览器属性、绕过验证事件或将逆向产物直接注册为 supported。需要官网 JavaScript 初始化匿名会话时，可以使用受控浏览器读取官方响应。
- **SSR-004**：同一官方列表承载多个招聘渠道时，可以复用底层协议，但每个逻辑渠道必须有独立 adapter key、记录级筛选和在线门禁，且不能把兄弟渠道职位混入结果。
- **SSR-005**：smoke 页内出现重复职位 ID、首页与末页总数漂移、页码/offset 不一致或访问验证时必须失败；采样运行应明确报告 `partial` + `sampled_pages`，不得伪称 `coverage=complete`。
- **SSR-006**：没有对应公开岗位的渠道只有在官网能够以完整空结果证明当前确实为零岗位时才可 supported；招聘首页、404 或无法判定的空响应不能作为成功证据。
- **SSR-007**：每个新增物理来源继续拥有独立配置、限流、健康、任务、SyncRun 和职位身份；不得用复合 adapter 合并独立官网故障域。
- **SSR-008**：晋级后 catalog、Registry、数据库 seed、Web/CLI 逻辑渠道摘要和支持矩阵必须一致，supported 物理来源默认启用。
- **SSR-009**：每个渠道必须有离线 Schema/分页/归一化测试和默认跳过的定向在线门禁；线上失败不得导致普通测试访问公网。
- **SSR-010**：完成标准为 catalog 中 45 个逻辑渠道全部派生为 supported、无 blocked/experimental required 物理来源，并在同一轮受控首页/末页 smoke 中通过。
- **SSR-011**：拼多多社招先验证官网 `anti_content` 生成器的输入、生命周期和可移植边界；只有在无需登录、用户 Cookie、stealth 或验证码规避，且连续三轮匿名会话均能生成逐请求 token 并通过首页/末页/详情 smoke 时，才可提议采用签名运行时。普通 Chrome 首屏后由 Playwright CDP 接管的 session-driven driver 必须保留为 fallback。

## 验收场景

1. 权威清单从 16 supported / 9 experimental / 20 blocked 逐步收敛到 45 / 0 / 0。（SSR-001, SSR-010）
2. 小米或网易直接 HTTP 出现访问验证时保持非 supported；只有正常匿名浏览器或稳定公开协议完成首页/末页 smoke 后才能晋级。（SSR-002, SSR-003, SSR-005）
3. 校园混合列表拆出的实习与校招分别只返回本渠道职位，并分别通过首页/末页样本证明筛选正确。（SSR-004）
4. 网易互联网、游戏、雷火校招继续作为三个独立物理来源运行，其中一个失败不影响另外两个。（SSR-007）
5. 全部晋级后 seed 仍保持 15 家公司、45 个逻辑渠道，物理来源数由真实官网拓扑决定，Web/CLI 默认同步只扇出有效来源。（SSR-008, SSR-010）
6. 拼多多签名 Spike 必须记录前端 bundle 身份、服务器时间依赖、逐请求 token 差异、浏览器 API 依赖和失败形态；不能以单次 token、重放成功或修改自动化指纹作为可行性证据。（SSR-003, SSR-011）

## 范围外

- 第三方招聘平台和搜索引擎结果。
- 登录后或仅员工可见的职位。
- 跨物理来源职位合并。
- 为达成数量目标而伪造渠道、职位或完整覆盖证据。
