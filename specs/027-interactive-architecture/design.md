# 交互架构文档设计

> 状态：Implemented

## 实现

这是公开的静态技术文档，不读取用户数据库，也不改变应用进程与依赖方向。无需新增 ADR。

`docs/arch/image/jobhunter.architecture.json` 保存两个视图的节点、坐标、类型、关系、说明及仓库路径。`scripts/architecture/` 内 TypeScript 生成器在构建边界校验数据、节点引用和位置，并生成自包含 HTML 与 SVG。网页使用原生按钮覆盖 SVG 连线；详情使用普通非模态侧栏。读图状态只保存在当前页面，不涉及业务数据。

浅色令牌从 `apps/web/app/styles/tokens.css` 自动内联；深色只作为静态文档的局部主题。图采用四列技术图纸布局，珊瑚色边线标识选中节点。系统架构图展示具体功能模块的运行时调用与数据访问，不将连接误称为包导入关系；领域与端口规则仍以总体架构为准。业务图展示信息流，项目经历由个人资料派生，额外文档与面经属于可选补充。同列跨行连线绕开中间节点，避免看起来穿过无关的职位池。

## 验证

求职流程的经历分支位于最上行：“项目经历/工作经历 → 面试准备档案 → 整理练习”；中间行保留简历导入、个人资料和制作，底行展示职位采集与申请。个人资料向上提供经历信息，当前项目拷打仍从项目条目建立档案，不因图示改名扩展业务能力。

生成器测试检查错误数据、引用完整性、项目来源链路、避障连线、转义和生成文件一致性。独立 Playwright 检查离线加载、关联选择、取消选择、搜索控件不存在、主题、导出、缩放、键盘、窄屏及减少动态效果，不启动 SQLite 或应用 Worker。
