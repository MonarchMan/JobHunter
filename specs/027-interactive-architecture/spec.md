# 交互架构文档

> 状态：Implemented

## 目标

帮助首次阅读仓库的开发者通过可编辑数据、静态预览和离线交互网页理解 JobHunter。

## 验收标准

- **ARCH-001**：系统架构图展示入口、业务编排、核心处理和数据与外部服务的运行时协作，不以抽象的领域、端口、契约作为主要节点；明确箭头不表示代码导入。求职流程必须展示简历解析后的个人资料、项目经历、面试档案之间的关系；额外上传文档与面经只作为补充材料说明。
- **ARCH-002**：支持取消选择、节点关联高亮与详情、缩放、复位、深浅主题和 SVG 导出，不提供搜索控件或残留搜索提示。键盘与窄屏能访问所有节点。
- **ARCH-003**：JSON 是图内容的唯一来源；生成网页与 SVG 可重复构建，网页无远程依赖并可直接离线打开。
- **ARCH-004**：README 提供预览与打开说明；保留上手指南。提供本地预览命令，不宣称尚未部署的在线地址可用。
