# 032 四模块业务聚合

> 状态：Ready

> 中央调度服务为已确认、待实现目标，见 [ADR-0062](../../docs/adr/0062-central-task-scheduler.md)；原有已完成项不代表新增目标已经验收。

> 依赖：000, 001, 002, 003

## 目标与当前状态

共享包已收敛为 recruitment、user、matching、common 四个 workspace 包，旧包与临时转发入口已删除。模块、分层、数据所有权和契约加载边界由自动门禁验证，完成证据见 tasks.md 与验收报告。

## 功能需求

- **BMC-001**：共享生产代码最终只能归属四个包；apps 仅保留 CLI、Web 两个入口，删除独立 Worker 包、入口和 worker start 命令。模块内部用目录组织能力，不为子功能另建 workspace 包。
- **BMC-002**：recruitment 拥有公司、官网与平台来源、采集连接器、职位、招聘邮件、申请进展和求职日历。邮箱凭据属于招聘接入数据；个人面试复盘属于 user，已确认的面试安排和申请阶段属于 recruitment。
- **BMC-003**：user 拥有简历文件、解析与 OCR、画像与偏好、简历草稿与模板、导出、项目与经历、面试档案、面经、研究和训练记录；user 表示个人求职资料及准备，不引入多用户账号体系。
- **BMC-004**：matching 通过 recruitment 与 user 的公开查询契约获取职位和用户快照，负责二者之间的理解、筛选、评分、排序、解释、建议及搜索条件派生；只写匹配自身数据，不回写职位或画像事实。
- **BMC-005**：common 拥有通用配置、日志、Clock/ID、数据库连接与事务、文件存储机制、队列与调度、通用 Agent/模型和浏览器运行能力；不依赖三个业务模块，不拥有业务 Schema、业务 Prompt 或业务仓储。
- **BMC-006**：允许的包依赖为 recruitment → common、user → common、matching → recruitment/contracts、user/contracts、common；recruitment 与 user 不直接互相依赖，也不反向依赖 matching。跨模块交互经公开契约和显式入口装配。
- **BMC-007**：每个模块内部保持纯领域、用例端口和适配器的单向依赖；持久化实现与业务 Schema 随数据所有者迁移。采用单一 SQLite，迁移执行器接收入口注册的模块迁移清单，common 不导入业务模块。
- **BMC-008**：CLI/Web 使用 common TaskClient 共用中央调度服务；apps 组合根装配业务处理器并提供内部服务/执行宿主，common 不导入业务实现。入口退出不停止共享任务；页面和命令只做协议适配，耗时任务、幂等与事务外网络约束保持。
- **BMC-009**：按阶段替换导入、exports、TS references、边界检查和测试，完成后移除旧包及临时转发入口。历史迁移路径或数据需要变动时按破坏性更新处理；涉及重要数据须先提交具体方案并征求用户意见，不在本方案阶段操作运行数据。

## 质量需求

- **BMC-Q01**：保留源码 development 条件与生产 dist 条件；契约入口不得间接加载浏览器、OCR、邮箱或模型 SDK，不通过巨型根 barrel 聚合所有实现。
- **BMC-Q02**：边界测试验证四包依赖、包内领域纯度、应用不导入具体适配器和跨业务数据写入隔离；现有功能行为由相关回归测试验收。

## 验收场景

1. workspace 仅保留四个共享包，旧包导入与转发入口均清除。（BMC-001, BMC-009）
2. 修改简历画像和面试准备只需在 user 内修改其业务实现与持久化，入口适配除外。（BMC-003, BMC-007, BMC-008）
3. matching 使用版本化快照计算结果，不直接查询其他模块表，不写回原始事实。（BMC-004, BMC-006）
4. common 不包含业务依赖，加载 contracts 不触发重运行时；故意违规导入可被门禁拦截。（BMC-005, BMC-Q01, BMC-Q02）
5. 邮件面试通知形成 recruitment 日程；user 准备材料通过上下文输入关联其 ID，用户提交面试复盘不会隐式修改招聘进展。（BMC-002, BMC-003, BMC-006）
6. 干净构建、开发启动、Worker 重试与恢复、相关功能测试通过；数据操作在获准前不执行。（BMC-008, BMC-009）
7. 通过实际 Next 服务打开每个 page.tsx 对应页面，包括具有有效记录的动态详情页；页面 HTTP、数据加载和客户端水合成功，不出现运行时异常或服务端 5xx，并运行完整页面交互浏览器套件。（BMC-008, BMC-009, BMC-Q02）
