# 个人资料页简历工作台改造记录

## 参考与边界

- 参考用户提供的 B 站校招长截图，吸收“解析入口、纵向章节、重复经历条目、章节导航”的信息结构。
- 结合字节校招常见简历结构，加入求职意向、工作偏好、技能领域与解析完整度。
- 保持 JobHunter 的档案靛蓝主题，不复制参考页面的品牌色、吉祥物或具体组件外观。
- 当前领域模型没有姓名、电话、邮箱、作品附件等字段，因此本轮不展示虚构值；这些内容作为后续结构化简历模型扩展方向。

## 页面调整

1. 导入简历卡片成为页面首要入口，保留 PDF/DOCX 自动解析，并明确标注 OCR 为规划能力。
2. 结构化简历增加解析完整度、关键摘要和缺失信息提示。
3. 桌面端增加粘性章节目录，移动端变为横向章节导航。
4. 教育、工作、项目使用编号时间线，清晰展示起止时间、角色和成果。
5. 增加求职意向与偏好分区，展示目标岗位、地点、用工类型、公司规模、远程偏好和排除词。
6. 技能与领域继续使用紧凑标签，并对能力等级使用中文标签。

## 后续建议

- 扩展领域模型以保存基础身份信息、语言能力、证书、社交主页、作品附件和自我评价。
- OCR 上线时增加文件级进度、失败重试、识别结果预览与用户确认，不应直接覆盖已维护字段。
- 结构化字段开放逐项编辑后，应提供草稿恢复、离页保护和字段级来源证据。

## 2026-08-26 编辑与预览升级

- 在线简历所有章节已改为可编辑，并补充基本信息、作品、竞赛、证书、语言能力和自我评价。
- 教育、工作、项目及新增列表章节支持添加和删除条目。
- 底部提供粘性“预览 / 保存”操作；保存整份资料并只生成一个画像版本。
- 预览使用可滚动应用内模态弹窗，展示当前未保存草稿，并隐藏空条目和空章节。
- 预览支持 Escape 关闭、焦点恢复与移动端全屏布局。
- 移除每个章节重复的 `RESUME SECTION` 英文眉题，保持中文标题单一层级。
- 修复预览、关闭预览和返回编辑按钮被主按钮 hover 规则覆盖的问题，统一为中性次级按钮反馈。
- 教育、工作、项目、竞赛与证书时间字段改为原生日历日期输入，在 Edge/Chrome 中使用平台提供的月、年快速切换。
- 教育、工作和项目的开始/结束日期合并为一个“起止时间”组；桌面端整组只占半行且与“学校”等普通字段等宽，组内两个输入同排等宽，所有新旧起止日期均以完整 `年-月-日` 显示，窄屏时整组扩为一行。
- 起止时间组移除可见的“开始日期”“结束日期”和预计日期提示，只保留组标题与日期控件；控件仍通过辅助技术名称明确区分起止含义。
- 起止日期增加应用拥有的 ISO 显示表面，固定呈现 `YYYY-MM-DD`，不再被 Windows/Edge 的 `日/月/年` 区域格式覆盖；透明原生输入继续负责日历、键盘与年月切换。起止时间标题改为普通字重，并与同行字段统一标签间距和输入框顶边。
- 职位列表中的职位名称改为直接打开官网详情；数据库读取历史职位修订时兼容真实的数组式 change set，避免首版 `[]` 触发站内错误页。
- “项目成果”更名为“项目描述”；“技能与领域”改为单一“专业技能”文本区，底层结构化技能继续供职位匹配使用。
- 提升章节、标签、输入和说明字号，章节 hover/聚焦时使用浅底色反馈；预览按钮移除图标。
