# 职位匹配评测基线

> 状态：Prepared
> Ruleset：`v1`
> JobAdviceAgent：`job-advice@1.0.0`

## 数据与指标

黄金集位于 `evals/job-matching/cases/`，只包含脱敏、最小化的画像和职位事实，不复制简历正文。评测器固定计算：

- Top-K 人工相关率，用于记录排序基线；无历史数据时不虚设目标值。
- 硬排除误杀数，发布门槛为 `0`。
- 建议事实一致性率，发布门槛为 `100%`；建议中的证据、缺失项和不确定项必须逐字来自确定性 MatchResult。

黄金集增长时应覆盖目标岗位、边界地点、未知经验、明确排除词和不同公司规模。修改规则集或 Prompt 后必须保留旧报告，并使用相同数据集生成可比较的新报告。
