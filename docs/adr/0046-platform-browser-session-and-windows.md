# ADR-0046：招聘平台浏览器会话、隔离与窗口所有权

- 状态：Accepted
- 日期：2026-09-28
- 关联规格：[028 招聘平台来源](../../specs/028-recruitment-platforms/spec.md)

## 决策

2026-09-30 补充：Worker 内浏览器级 Socket 的共享及释放时机由 [ADR-0054](0054-worker-shared-cdp-transport.md) 覆盖；以下页面所有权、业务会话隔离和授权边界保持不变。

每个内置 provider 绑定稳定来源 ID、公司命名空间、任务类型、活动会话及代次。服务、仓储、并发键、幂等键和 Web 状态按 provider 隔离；写入事务还要核验任务类型。未装配连接器不展示为可用能力。默认同一 Chrome 配置、每平台一个账号，不建立账号池或配置选择器，也不读取浏览器磁盘 Cookie 数据库。

用户明确连接／获取后，Worker 从本机 Chrome 的固定 `DevToolsActivePort` 位置发现连接；自定义位置可通过既有配置指定。每个平台在默认浏览器上下文创建自己的专用页和独立后台窗口，共享该配置的登录态，不枚举、接管、搬移或刷新用户已有页。先创建空白页并安装必要监听，再导航到该平台固定入口；活动批次复用同一页和 CDP WebSocket。窗口策略与 HTTP/browser 数据传输解耦，后台创建不保证绝对无焦点干扰。BOSS 显式 `backgroundWindow=false` 仅作调试兼容；显式 `targetId` 借用用户页时不创建窗口、也不取得关闭权。

一次人工授权的 CDP WebSocket 在活动平台会话内持续复用，到显式断开、替换、Worker 退出或连接异常才释放；不因单次任务或 HTTP 失败主动关闭、重建。HTTP 模式在完成必要初始化后可 detach 页面，但保留授权 Socket；需要页面监听的协议可以保持 attach。意外断线使该会话失效、取消在途请求、清除内存认证与工作集，不自动重连冒充同一代次，也不为清理残留页重新申请授权。显式断开或替换只关闭本会话自建页，不关闭浏览器、其他 provider 页或借用页；迟到结果提交前复核代次。页面级状态不保证跨页共享，登录共享不等于查询模板自动继承。

“职位”页与来源页共用日常获取操作：选择具体平台后复用健康会话，否则在本次明确操作中自动连接并读取一批。冻结会话不能靠普通获取绕过；应走已有恢复或显式重连／手动重试路径。Web 不要求手填目标标签 ID，描述文件路径仅留高级备用；CLI 的显式目标参数仍用于调试。只读状态、筛选、组件挂载与本地结果刷新都不发布采集任务。浏览器权限和前置登录由用户控制；项目不自动处理验证码。

## 边界与验收

授权等待与各命令超时沿用规格；失败并不证明用户登出，也不承诺 Chrome 重启后免授权。新窗口规则只作用于新连接，不搬移已有会话；重新建立会话必须产生新代次，不能将旧样本拼成连续稳定观察。验证 provider 相互隔离、先监听后导航、同 Socket 复用、冻结保护、自建页所有权清理以及借用页不关闭。
