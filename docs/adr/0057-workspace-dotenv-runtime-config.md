# ADR-0057：运行参数统一使用工作区 .env

- 状态：Accepted
- 日期：2026-10-23

## 决策

取消 JSON 运行配置及 `--config`，CLI、Web、Worker 共用工作区 `.env`。优先级为 CLI 临时参数 > 进程环境 > `.env` > 内置默认值，配置模板仅保留 `.env.example`。

## 原因与影响

双配置文件使参数位置和优先级难以理解。日志、平台间隔、Worker 和模型参数均可由环境变量表达，统一后无需维护文件配置层。已有 JSON 参数手动迁移，init 不再生成 JSON。邮箱账号、游标和加密凭据属于独立运行数据，存储位置仍由环境变量指定。
