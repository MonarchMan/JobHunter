# ADR-0028：智联校园使用已观察请求模板初始化 HTTP 会话

- 状态：Accepted
- 日期：2026-09-20
- 关联规格：[028 招聘平台来源](../../specs/028-recruitment-platforms/spec.md)

## 背景

智联校园推荐使用包含登录与意向上下文的 POST。资源时间线只有 URL，不能恢复正文；自行猜测字段曾返回业务码 210。真实浏览器请求模板已通过独立 HTTP 最小闭环。

## 决策

沿用 ADR-0026 的单连接寿命。连接指定校园推荐页，在初始化的 120 秒窗口内监听一次用户正常分类切换产生的首页请求，只接受该目标会话与固定端点。取得模板并通过边界校验后停止 Network 监听、detach 页面，保留空闲 WebSocket；不自动导航、点击、刷新或执行签名生成。模板及认证字段只在 Worker 内存，后续列表与详情由受限 HTTP 会话执行，不向 CLI、Web、任务或日志暴露。

共享底层 CDP 传输和生产 UI，但 BOSS 与智联各自拥有连接、代次、仓储、任务与错误状态。CLI 默认 BOSS 保持兼容，智联显式选 provider；Web 仅开放已装配平台，并明确校园范围。生产主动断开关闭自己拥有的连接；测试借用用户要求保留的研究连接时不取得其所有权，不关闭该连接。

## 后果

2026-09-20 扩展：同一 provider 增加主站 `/jobs` 页面，按明确目标页固定协议，不新增来源身份或连接池。主站在同一初始化窗口内观察搜索 POST 与详情 GET 双模板，验证认证上下文一致再装配独立主站 HTTP 会话；正文解析仅增加已观察的无属性 div。官网查询在连接时固定，变更须显式重新连接。共享 CLI／Web 改用能兼容搜索的职位文案，校园与主站协议及测试仍独立。智联请求间隔按用户确认改为至少 5 秒，不视为平台承诺。其他筛选参数必须取得证据后扩展，不能静默忽略。

首次连接需要用户在授权后切换一次校园推荐分类，超时可显式重新连接；不承诺零浏览器依赖或长期令牌有效。连接成功不等于 HTTP 可用；首次真实推荐成功后才进入 available。失败冻结、不自动恢复，未验证分页与长期稳定性不能据此晋级。
