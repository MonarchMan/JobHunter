# ADR-0060 用内容身份替代业务版本选择

## 状态

已接受，取代 ADR-0056 的 Agent 手动版本治理。用户于 2026-11-05 明确批准删除规则、Agent、Prompt 版本、旧实现和兼容分支。

## 决策

仅运行当前规则和提示词，不再维护或选择历史算法。Agent 保留功能 key，执行定义以提示词、输入输出契约、工具和限制等实际内容计算哈希；缓存必须随这些内容改变而失效。历史评分、用量和运行记录保留快照，不承诺历史重放。规则定义使用内容身份而非手写版本，数据库迁移顺序不变。

面试调研的执行能力使用明确协议标识，不通过 Prompt 版本推断浏览器或本地执行模式。删除版本展示及失效兼容代码；业务数据修订、数据库迁移和独立外部协议的标识不在删除范围内。
