# ADR-0059：模型请求账本独立于 Agent 运行

状态：Accepted

日期：2026-11-04

## 背景

用量页需要逐请求查询、筛选及长期保留账单。原 agent_runs.model_usage_json 随整次运行结束才写入，运行清理会删除账单，时间筛选需要展开所有 JSON 数组。

## 决策

common 新增 model_requests，一次 HTTP 请求对应一个客户端生成的稳定 ID。请求开始登记 running，结束更新 completed 和已知账单；HTTP 错误、协商回退、取消均独立记录。未知费用和时延保留 NULL，不用运行结果推测。

账本使用可空 agent_run_id 外键 ON DELETE SET NULL，并保留 agent_key 快照。运行表不保存请求 ID 数组；读取时从外键反查 ID 与账单。账本是逐请求事实来源，运行级汇总保留用于旧数据和诊断。模型适配器经纯回调契约通知运行时，后者调用仓储端口；数据库事务不跨网络等待。

生成速度由输出 Tokens 与总耗时减首字延迟计算，不新增重复的速度列；生成速度的原始计量分量保留。列表仅返回运行摘要，展开详情才加载关联请求。

迁移将旧数组逐条转换为账本，使用原 run ID 和数组位置组成稳定迁移 ID，原值不重算；事务成功才删除旧列。仅有运行合计的历史数据不伪造请求。实际用户库迁移需备份和确认。

## 后果

运行清理不再改变消费历史；请求完成后立即可查，时间索引可用于范围扫描。崩溃时正在执行的请求仅能保留开始记录，不能恢复供应商尚未返回的用量。账本保留策略今后单独定义；不新增供应商、应用、日汇总或定价管理表。
