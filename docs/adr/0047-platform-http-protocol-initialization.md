# ADR-0047：智联与前程无忧的 HTTP 协议初始化

- 状态：Accepted
- 日期：2026-09-28
- 关联规格：[028 招聘平台来源](../../specs/028-recruitment-platforms/spec.md)

## 智联

校园推荐页仍在受限初始化窗口内观察用户正常分类切换产生的固定 POST，请求模板经边界校验后供独立 HTTP 会话使用。显式主站调试页可观察正常搜索与详情请求模板，查询固定在连接代次内。日常自动连接则只打开 Worker 自有的独立后台主站首页，从同一自然首页请求取得 `at`、`rt`、`resumeNumber`；请求正文与查询字段必须一致，不跨请求或账号拼接。`resumeNumber` 只在已验证协议内可作为 `cvNumber`，不是跨平台身份等价规则。缺少字段明确报 `auth_context_missing`；不读取简历响应或磁盘凭据。

自动连接需要显式非空关键词，在创建窗口前校验；城市和排序采用已支持的默认或显式值。认证与普通搜索条件分开，认证仅留 Worker 内存，查询可作为任务参数保存。连接阶段不点击搜索／职位、不刷新、不发送职位 HTTP；用户明确获取后，才由现有 `ZhilianSearchHttpSession` 按已验证协议构造并发送列表、详情 HTTP。活动连接不接受新查询，换条件要重新连接。接口拒绝或结构未知时停止，不自动扩大认证字段或回退浏览器采集。

## 前程无忧

`Job51HttpSession` 使用官网已正常产生的搜索请求作为最新有效模板，含签名与动态访问参数。Worker 只读监听所选搜索页的固定端点；用户正常搜索或翻页后，显式批次获取才按原样模板发送独立 HTTP。不自行生成签名、修改页码、自动翻页或用旧模板冒充新批次；缺少新模板报告 `template_required`。该 provider 需要持续监听，是其他平台初始化后可 detach 的例外。请求模板及认证有界保存在本会话内存，断线、关闭页面或退出即失效。

列表 JSON 已有完整正文时直接作为详情事实入库，不重复 HTTP。重复页、查询变化与未知结构拒绝；官网未产生新批次不能当作自然末页。UI 明确提示“先在官网搜索／翻页，再读取批次”，不宣传零浏览器依赖或自动连续分页。

## 边界

两个 provider 均只允许已验证的请求结构与固定端点；认证不进入任务、数据库、Web 状态或日志。连接成功不等于整批或长期稳定，真实 HTTP、详情、隔离入库与后续批次应分别验收。请求节奏使用现行可配置策略，不沿用旧 ADR 中的固定五秒实验值。
