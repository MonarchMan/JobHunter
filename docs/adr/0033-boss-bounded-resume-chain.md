# ADR-0033：BOSS 同批次有界显式恢复链

- 状态：Accepted
- 日期：2026-09-21
- 部分替代：ADR-0032 的一次有效恢复上限。
- 临时只读传输故障按 ADR-0034 在独立预算内重试；耗尽后仍终止恢复链。

## 背景

官网正常更新上下文后，HTTP 已实际恢复并保存五条，但随后再次 37。一次恢复即丢弃剩余工作集会使后续只能重抓整批。延长请求间隔并未解决此问题。

## 决策

同一原始批次最多五次有效恢复，不自动循环。每次必须显式确认官网正常，并验证稳定认证绑定未变、安全上下文相对最近失败已经更新；继续使用原授权连接与 HTTP。每次恢复引用最近一次有未完成详情的失败任务；仅上下文未更新的检查失败不替换该引用，不消耗有效恢复次数。

原批次十分钟期限不得因恢复延长。每次只保留尚未提交的候选，独立任务分别记录本次保存量和直接前序任务；旧任务不改写。第五次恢复再次失败后不可继续。取消、断线、换代、重启、普通认证变化或非 37 错误均终止恢复资格。

## 验收与边界

覆盖多次恢复不重抓、旧任务引用拒绝、五次上限、原始期限、上下文不变及中止边界。在线先验证一批剩余集合完整入库；不把单批恢复完成当作无 37、持续翻页或长期稳定。浏览器只提供正常产生的上下文，不生成安全令牌、不回灌挑战、不自动处理验证码、不刷新页面。CLI／Web 应用命令沿用原入口，本次不增加 UI 自动恢复。
