# ADR-0065：单宿主与有界动态任务线程池

- 状态：Accepted
- 日期：2026-11-06
- 替代：ADR-0062、ADR-0064 的生命周期与执行隔离决策。

## 决策

每个规范化数据目录只允许一个 Web/CLI 宿主。主线程统一调度，所有业务 Handler 交给有界动态 Worker 线程池，线程内异步并发。宿主停止即停止执行，取消独立后台服务及执行进程池。Web 启动器拥有运行时，Next 使用受限命令桥；CLI 只推进目标工作流并等待。

线程预算、活动任务预算、类型并发及网络并发独立。会话固定所属线程并阻止缩容，故障撤销分派后恢复。保留事务门控、检查点、幂等与既有重试预算。

## 影响

统一入口和任务生命周期，避免入口结束后继续调用模型。增加线程扩缩容、消息及会话管理；原生模块崩溃仍可能影响宿主，外部浏览器仍需回收。完整设计与验收见 [003 设计](../../specs/003-task-worker/design.md)。
