# ADR-0036 招聘平台使用 Worker 专用标签页

## 状态

Accepted；替代 ADR-0035 的日常已有页面发现与歧义选择决策。

## 决策

- 默认单一 Chrome 配置、每个平台单一账号，不建设配置选择器或账号池。
- 日常连接在已授权 Chrome 的默认浏览器上下文中新建一个平台专用标签页，共享该配置的登录态；不枚举、接管或刷新用户已有页面。
- 先建立空白页、附加监听，再仅导航一次到固定平台入口，避免遗漏初始化请求。BOSS、智联、前程无忧、猎聘分别使用推荐页、主站搜索页、搜索页、学生首页。
- 一个平台活动会话复用自己的标签页和 CDP 连接；读取批次不另开页面，不刷新。HTTP 优先及各平台已有能力边界不变。智联初始化仍可能需要用户在新页搜索并打开详情，前程无忧仍依赖新页正常搜索产生的模板。
- 显式断开、替换连接或初始化失败时，只清理当前会话创建的标签页；不关闭浏览器或用户页面。意外断线后不为清理而自动重连，可能遗留的专用页由用户关闭。批次结束不关闭会话。
- Web 不再提供标签页 ID 或多页面选择。描述文件路径仅作为高级备用。旧 CLI 显式 targetId 调试入口暂保留兼容，只有显式传入才借用指定页面，不归日常自动连接；借用页永不由 Worker 关闭。
- 不修改正在运行的历史已授权连接；新规则从新建连接生效。登录态共享不保证页面级令牌、查询条件或 sessionStorage 共享，不复制用户页私有状态。

## 验收

以模拟 CDP 验证新建、监听先于导航、单次导航、会话复用、失败清理及不关闭用户页；以隔离 Web 测试验证免标签选择的获取和高级路径校验。离线通过不代表四个平台新入口在线初始化已验收。
