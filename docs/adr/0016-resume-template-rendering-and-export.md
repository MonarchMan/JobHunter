# ADR-0016：版本化简历模板与 Worker PDF 导出

> 状态：Accepted
> 日期：2026-09-01

## 背景

现有在线简历是画像事实的编辑器，而参考 HTML 同时承担样式、任意 DOM 编辑和打印，无法安全复用，也无法保证多模板一致性。

## 决策

1. 投递稿由个人资料派生但独立持久化，修改不回写画像。
2. 内置模板通过版本化注册表发布；React 画布、HTML 与 PDF 使用同一渲染定义。
3. Web 只生成不可变 HTML 快照和入队；Playwright PDF 只在 Worker 执行。
4. 导出快照为最长 24 小时的临时本地文件，不作为永久简历历史。
5. 用户头像属于投递稿，并随拥有它的个人资料删除。

## 结果

新增模板无需数据库迁移；旧草稿需保留对应版本渲染器。PDF 生成可以重试且不会在 Web 事务中运行浏览器。导出快照和头像进入敏感数据删除影响范围。
