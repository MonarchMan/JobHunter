# ADR-0019：任务诊断写入投影与批量读取

- 状态：Accepted
- 日期：2026-09-05

任务列表每次解析 JSON 和遍历重试链，产生不必要的同步数据库开销。
在 tasks 中保存 source_id、source_run_id、retry_root_task_id 派生字段；
迁移回填历史记录，插入触发器统一维护仓储及直接 SQL 入队。
这些字段不改变任务输入与重试关系的所有权，应用层仍通过诊断仓储端口读取。
任务 payload 和 retry_of_task_id 在入队后视为不可变；状态变更无需重算索引。
普通任务安全详情批量关联来源与运行，避免按页大小增长的往返查询。

代价是每次入队增加一次行更新及索引维护；收益是列表无需实时递归或读取详情原文。
