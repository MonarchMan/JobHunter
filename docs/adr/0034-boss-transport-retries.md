# ADR-0034：BOSS 网络重试与安全上下文恢复独立计数

- 状态：Accepted
- 日期：2026-09-21
- 补充：ADR-0033；只扩展临时只读传输故障，37 恢复策略不变。

## 决策

BOSS HTTP 同批次最多三次额外传输重试，独立于五次显式 37 恢复计数。仅覆盖已识别的临时网络错误及 HTTP 429、500、502、503、504；网络重试当前 GET，不回退列表、不重抓已提交职位，不要求安全上下文必须变化。每次依旧读取所选浏览器当前认证，读取失败不能用旧上下文降级。

退避为 5、10、20 秒；合法 Retry-After 取与退避的较大值，超过原批次剩余期限则终止，不提前重试。取消、断线、身份／解析错误、未知传输错误及预算耗尽均终止；37 立即暂停，只能走官网正常更新后的显式恢复，不消耗网络重试次数。十分钟批次期限覆盖重试等待，恢复不能重置网络预算。

## 验收

离线覆盖传输恢复不重复保存、两种预算独立、HTTP 退避、取消和期限；真实只验一批且记录所有请求。单批通过不表示消除服务端 37 或长期稳定。
