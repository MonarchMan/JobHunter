# ADR-0051：职位只保留当前内容

> 状态：Accepted
> 日期：2026-09-29

## 决策

个人求职场景不再保留职位历史快照。jobs 身份稳定，内容变化原地更新；job_revisions 沿用现有内部契约名称，但每个职位只保留一条当前内容。内部 ID/序号作为内容代际标识，在更新时替换，以拒绝旧评分任务迟到写回，不作为用户可浏览的版本。

迁移保留最高序号的内容与对应结果，删除其他内容及关联的职位理解、评分和建议。以后更新时同样删除旧结果并取消仍引用它们的任务；不自动重新评分。观察时间和来源运行记录保留，观察引用转到当前内容，不再用于还原历史 JD。

## 实现与安全

SQLite 在内容插入的同一语句内通过触发器清除该职位旧内容；删除前先取消相关任务、删除建议/评分/理解，再重绑观察引用。外键阻止旧 ID 的结果写回。所有官网、平台和详情写入共用此不变量，事务外不可观察到多份内容。变更集合清空，避免其中的 before 字段变相保留旧全文。

存量迁移前使用 SQLite 在线备份，迁移事务失败回滚。历史不可在产品内恢复，只能从备份恢复。Agent 运行诊断及任务执行日志仍按原保留策略管理，不作为职位历史展示。

## 后果

减少存储和界面复杂度；放弃职位历史比较。职位变化后需用户重新评分。画像和规则集版本不受影响。
