# ADR-0017：网友面经来源正文仅用于瞬时核验

> 状态：Accepted
> 日期：2026-09-04
> 部分取代：ADR-0015 的第 7、8 项

## 背景

网友面经页面已提供原始来源链接，长期保存并展示问题周边的证据摘录会重复第三方内容，也增加研究 Bundle、业务表和界面的负担。用户需要核对上下文时，可以直接打开原始发布页。系统仍需防止研究 Agent 编造问题，因此不能删除采集阶段的来源校验。

## 决策

1. `community-research-prompt@v4` 与 `community-research-bundle@v2` 不再定义 `evidenceExcerpt`；严格 Schema 拒绝仍携带该字段的研究包。
2. 浏览器辅助执行器继续在单次任务内使用有界页面正文和调用 trace，要求 `question.text` 与非空 `answerExcerpt` 逐字存在于同源正文。该正文只存在于 Worker 内存、Codex stdin 和任务临时资源中，任务结束后清理。
3. `interview_question_entries` 删除 `evidence_excerpt` 列，应用端口和网友面经页面同步删除该字段。持久化内容只包括问题、可选答案摘录、主题、来源元数据和原始来源 URL。
4. 用户核对问题上下文时，通过安全的新窗口链接“查看原始来源”；系统不镜像问题周边正文。
5. 版本化 Prompt 和 Bundle Schema 参与请求指纹。旧请求不原地升级，也不再由当前执行器继续运行；用户需创建使用新契约的研究请求。

## 影响

- 本地数据更小，页面信息层级更直接，也降低第三方正文的长期留存范围。
- 来源页面失效后，系统只能保留问题与来源元数据，无法提供本地证据快照；这是减少本地存储的明确取舍。
- 真实性门槛没有降低：自动采集仍在持久化前做逐字校验，人工导包继续标记为 `unverified` 并经过用户审核。
