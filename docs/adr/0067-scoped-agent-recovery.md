# ADR-0067：按任务步骤恢复 Agent 执行

- 状态：Accepted
- 日期：2026-11-10

普通 run 不保存输出正文，也不跨执行复用结果。runStep 使用 taskId、stepKey、resourceKey 和输入、定义、模型身份定位恢复结果；这不是全局内容缓存。运行创建时保存任务步骤关联，成功模型调用后的业务提交失败可直接复用本次结果。任务成功、取消、删除时清除恢复输出，账单和诊断独立保留。

AI 对话使用普通调用，无自动重试，回复只归 messages。邮箱分类按邮箱、消息和版本作为资源身份，并通过持久化未完成引用恢复业务提交。模型响应到结果落库之间的崩溃窗口仍可能导致重复外部调用，不承诺严格一次。

Agent 不重复保存 task_attempt。分派轮次及租约归 tasks；中央领取事务将 pending 任务关联的遗留 running Agent 标为中断，新执行者再沿用原 ID 恢复。运行中的任务不会被领取，旧执行者的写入继续受 owner、attempt 和有效租约门控保护。
