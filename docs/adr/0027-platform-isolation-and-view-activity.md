# ADR-0027：平台实例隔离与显式浏览活动

状态：Accepted

日期：2026-09-20

## 背景

BOSS 最小链路曾在仓储和任务工厂内固定平台身份；扩展智联、前程无忧与猎聘需要隔离连接、任务与数据。同时，清理已有交互时间字段，但详情浏览未记录，后台采集却更新了交互时间。

## 决策

内置 provider 定义绑定稳定来源 ID、公司命名空间、任务类型；每个服务与仓储实例只拥有一个 provider。任务并发、幂等和 Web 历史投影按 provider 分开；写入事务核验任务类型，BOSS 原有来源 ID 与外部协议保持兼容。未实现连接器不注册生产能力，不引入账号池或动态插件加载。

可见详情页以同源 CSRF POST 记录本地浏览，应用端口执行同步短 UPDATE，避免 Worker 排队延迟使清理忽略真实交互。GET／预取／隐藏页不写入；后台成功核验仅更新 last_seen_at。清理执行和引用重检继续留在 Worker。Web 从只读设置投影展示真实启用状态，禁止暴露预览令牌。

## 后果与验证

平台身份在同名、相同外部 ID 和相同代次下仍隔离；断开一个平台不影响另一个。直接交互写入与清理事务在 SQLite 写锁下串行，不承诺恢复已经删除的职位；写入失败需要可见反馈。保留策略仍为平台类别共用、官网独立，首版不增加逐平台策略配置。用隔离 SQLite、模拟连接器和本地浏览器验证，不请求真实平台。BossHunter 仅作为平台命名及职责拆分参考，不移植其代码或授权外的自动投递能力。
