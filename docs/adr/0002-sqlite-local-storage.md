# ADR-0002：SQLite 与本地文件存储

- 状态：Accepted
- 日期：2026-08-19

## 决策

个人使用阶段采用 SQLite WAL 存储结构化数据，本地 `var/` 存储大型原始响应、简历和导出文件。持久化通过 Repository 端口访问。

## 原因

该方案部署依赖少、备份简单，能够满足单用户和单 Worker 的吞吐。大型内容外置可避免数据库无限膨胀。

## 后果

必须使用短事务、单写并发、外键、`busy_timeout` 和一致性备份。出现多用户、远程部署或持续写竞争时，以 PostgreSQL Repository 替换，领域层不变。
