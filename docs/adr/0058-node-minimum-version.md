# ADR-0058：以最低版本声明 Node 支持范围

> 状态：Accepted
> 日期：2026-10-29

## 背景

ADR-0007 的 Node 24 LTS 基线被实现为仅允许 24 主版本的安装阻断，导致 Node 26 无法安装依赖。

## 决策

Node.js 支持范围改为 >=24，由 package.json engines 声明最低版本，移除 preinstall 版本检查脚本。doctor 保留最低版本诊断，24 及以上均通过。本决策替代 ADR-0007 中仅支持 Node 24 的运行时约束，其他包边界决策保持有效。

## 影响

新主版本可直接安装和运行；原生依赖兼容性通过实际安装、初始化和自动化测试验证。
