# ADR-0021：Agent 业务校验与评分阶段恢复

- 状态：Accepted
- 日期：2026-09-05

## 背景

职位建议先通过 JSON Schema 并进入成功缓存，随后才校验引用原文。模型重述证据会被拒绝，但手动重试仍命中该成功缓存；已完成评分也被整体任务失败掩盖。

## 决策

1. 匹配契约包提供确定性证据目录和 ID 解析器，模型仅引用目录 ID，系统还原持久化原文。升级建议 Agent、Prompt 与输出版本为 2.0.0，隔离旧缓存；不修改历史 MatchAdvice 数据格式。
2. Agent 定义提供纯业务 validateOutput 回调；运行时在成功提交、缓存命中及并发胜者返回前校验。无效成功缓存条件更新为 failed，保留审计与用量。引用校验与 JSON/Schema 错误共享既有单次纠正、时间与用量预算。
3. TaskExecutionError 可携带安全的部分结果，队列在失败或退避时写入既有 result_json。处理器通过 retryPayload 恢复同一输入已完成的阶段；普通任务保持原行为。
4. 手动评分中建议失败明确报告“评分完成，建议生成失败”，检查点记录评分 ID、职位修订及画像版本。重试只执行建议，并在读取评分时验证输入绑定，不新增任务状态或跨事务模型调用。

## 影响与验证

业务规则仍由匹配契约包拥有，运行时只调用纯验证端口，应用层不反向依赖数据库。测试覆盖 ID 还原、拒绝未知引用、单次纠正、坏缓存失效、缓存重用、评分保留与建议恢复。模型文本与引用的语义一致性仍不是 ID 存在性检查可以完全保证的。
