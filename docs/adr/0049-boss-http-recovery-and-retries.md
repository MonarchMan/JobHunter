# ADR-0049：BOSS 显式 HTTP 的有界重试与会话恢复

- 状态：Accepted
- 日期：2026-09-28
- 关联规格：[028 招聘平台来源](../../specs/028-recruitment-platforms/spec.md)

## 适用范围与诊断

仅适用于用户显式选用 BOSS `http` 的批次详情；日常 `browser` 模式不进入此链。Node HTTP 获取列表和全部职位详情，浏览器只提供当前合法认证／安全上下文。已保存职位不重抓，列表 37、非 37 业务错误及解析错误不进入详情恢复。保留上游原业务码、发生接口、前序成功、上下文变化和脱敏错误说明；不把所有 37 归因于频率或 Cookie 过期，也不宣称知道服务端唯一触发规则。

详情 37 后在原 Worker、会话代次与任务内保留未完成稳定 ID 和内存访问参数，最长十分钟；原列表和已提交详情不再请求。复核 `wt2`／`token` 认证绑定未变，`bst` 当前存在且允许正常轮换，安全上下文相对本次失败已更新，才重试失败详情并续跑。立即检查不满足时，在原期限内每五秒只读复核，不发送职位探测；取消、断线、身份变化、读取失败、换代、过期或预算耗尽即停止。自动与显式恢复共用同批最多五次有效续跑；未更新的只读检查不耗有效次数，恢复不延长十分钟期限或另建任务。

用户已明确允许受限的浏览器会话更新：仅 Worker 自有且仍在正常职位页的后台页，每次详情 37 最多对本批失败职位执行一次普通链接点击；浏览器响应只用于官网正常维持会话，绝不作为 HTTP 职位事实。允许官网自行经过一次安全检查路由并自然返回；若出现人工验证、额外导航、未返回正常页或身份／上下文未通过复核，停止。借用用户页不自动点击，不刷新、不重连、不切换传输、不生成安全令牌、不回灌检查参数。复核通过后仍由 Node HTTP 取得失败详情与后续详情。此模式依赖浏览器恢复，不是“纯 HTTP”。

临时传输故障与 37 恢复分开计数。BOSS HTTP 对已识别的网络瞬断及 429、500、502、503、504，单次请求最多额外重试三次；退避 5／10／20 秒，合法 `Retry-After` 取较大值，均受原批次期限约束。每次重新取当前合法认证，不用过期凭据降级；不重抓已提交职位。37、认证读取失败、身份／解析错误、取消及未知错误不走网络重试。恢复也不重置网络预算。

## 验收边界

验证两种预算独立、原任务与原期限、上下文未变不发 HTTP、跨候选不重抓、人工验证和借用页停止、迟到响应不提交。已有在线隔离批次曾在两次正常官网会话更新后用 Node HTTP 保存十条详情，但这只证明该批次路径可用，不证明跨批或长期稳定；`Set-Cookie` 同步本身不足以完成浏览器安全上下文更新。
