# ADR-0063：通用 AI 会话与本地项目关联

- 状态：Accepted
- 日期：2026-11-05
- 实施：画像列存储、通用会话、本地项目位置和面经阶段任务均已实现；已完成整体检查、备份演练和真实数据迁移（2026-11-06）。

## 决策

采用 [034 规格](../../specs/034-ai-sessions-and-projects/spec.md)。模拟面试改为无截止状态的通用会话，对话消息为交互权威数据；可选业务关联使用会话元数据。画像为项目事实唯一来源，本地路径仅引用项目位置，不接管文件管理。移除项目档案快照、二次知识及回答历史，画像提取通过预览确认应用。外部面经研究通过任务指定本地 JSON 输出路径交付并由系统校验，取代用户上传研究包。

## 边界

本决策替代 020/023/024 中与上述存储及交付流程冲突的旧约束；未冲突的来源验证、人工审核与隐私约束保留。指定结果文件写入属于明确开放的受限能力，不因此赋予 Agent 读取个人资料或数据库权限。模型上下文管理另行设计，不自动读取项目目录。

## 验证

先完成三阶段代码、测试库迁移和页面验收，再备份迁移现有数据，最后对实际上下文行为出具说明；未完成项目不得标为已实施。
