# ADR-0023：官网原始请求运行时驱动

- 状态：Accepted
- 日期：2026-09-11

## 背景

快手社招和日常实习的普通 HTTP 与捕获模板后直接修改页码重放尚不能工作，但正常官网页面加载后调用其已加载的公开职位请求方法可以取得指定页容量的 JSON。校园站采用不同版本的同类请求模块，独立提供应届和校园实习项目。

## 决策

继续使用 SourcePageClient 与 Worker 的隔离匿名浏览器。增加快手专用运行时驱动，在无职位列表的官网首页初始化已加载模块，通过 webpack runtime 的固定模块路径获取原始公开 API，仅调用白名单中的列表、招聘项目和字典方法。代码与导出形态均由实际官网验证；形态变化及无法识别的业务失败报 parse_changed，无浏览器报 access_blocked，导航超时/取消报 temporary，不自动扫描候选模块或复制签名实现。

原始模块运行在真实官网页面内，保留官网自己的请求处理，不修改浏览器指纹、不使用用户 Cookie、不处理验证码。浏览器驱动经 SourcePageClient 只返回已校验白名单公开字段；会话凭据不持久化、不输出日志。元数据与列表请求至少间隔 5 秒，沿用既有资源释放与熔断，单次请求 30 秒、整次采集 300 秒截止。

源代码中的公司协议、模块路径、方法名、项目分类与字段 Schema 由 packages/sources/companies/kuaishou 拥有；Worker 仅拥有 Playwright 调用与串行采集生命周期。应用层、领域层与数据库不依赖浏览器。不得将这一路径扩展为任意脚本、任意模块或任意官网操作接口。

实习逻辑渠道映射日常实习与校园实习两个 required 物理来源。应届校招与校园实习分别使用官网当前最新年级的 fulltime/intern 项目，每次初始化从官方项目列表发现，项目缺失或歧义报错而非默认为零。

## 验证与后果

2026-09-11 补充滴滴 Moka：沿用相同决策，在官网加载的 webpack5 注册表中定位已验证模块 `0wyxq0`，调用其 default(path).post(body) 处理公开列表和详情响应。仅允许 didiglobal 的 6222（实习）、96064（常规校园）、116021（未来精英）三个站点和已验证职位 API，不复制响应解密实现或访问候选人接口。滴滴社招保持匿名 HTTP。公司协议仍属于对应公司目录，Worker 只编排生命周期；未来精英无真实详情证据，保持实验状态。无列表正文先取得详情再入库的决策另见 [ADR-0024](0024-required-job-detail.md)。

快手四个物理来源各自完成生产适配器首页/末页及一条详情验证，才将三个逻辑渠道晋级 supported。采样始终报告 partial；不全量遍历。官网前端模块版本变化可能使驱动失效，因此离线测试覆盖运行时缺失、业务失败、频道错配、分页不完整，在线测试默认跳过且可按物理来源选择。

没有新增进程、登录状态或跨来源数据合并，也不放开 OSE-010 的生产 DOM 翻页限制。
