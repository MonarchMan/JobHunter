# ADR-0056 Agent 行为版本格式与变更授权

## 状态

已接受

## 决策

所有 `AgentDefinition.version` 使用 `MAJOR.MINOR.PATCH` 三段式版本，例如 `1.0.0`。该字段只表示 Agent 行为契约版本，不替代 Prompt 版本或输出 Schema 版本。

版本号参与缓存键、运行记录和结果隔离，因此任何版本号修改都必须在实现前取得产品负责人明确同意，并在规格或变更说明中记录批准依据。没有明确同意时不得递增、回退或重命名版本。

本次迁移对历史运行记录执行破坏性归一化：`v1`、`v2`、`v3` 分别改写为 `1.0.0`、`2.0.0`、`3.0.0`；后续不保留旧格式。

## 原因

统一格式便于页面展示、排序、缓存审计和自动校验；授权要求避免 Agent 行为在未确认的情况下改变并造成不可追溯的缓存分叉。
