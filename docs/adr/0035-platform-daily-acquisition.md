# ADR-0035 招聘平台日常获取与自动连接

## 状态

Accepted

## 背景

职位页跳转来源页手填 CDP 路径和页面 ID 是工程验收入口，不能作为日常获取流程。保持 Worker 持有凭据、用户显式授权、HTTP 优先和单批上限。

## 决策

- 职位页与来源页复用 PlatformBrowser；选择具体平台后原地获取一批、展示进度并刷新本地职位结果。全部平台不隐式选择账号或发起四平台采集。
- 新 acquire 命令在 Worker 中校验预期代次，复用健康会话；无会话时自动连接后读取一批。冻结会话不得借此绕过错误或重置游标，须显式恢复或重新连接。
- 自动连接仅读取当前系统 Chrome 的固定 DevToolsActivePort 位置，允许通过 JOBHUNTER_CHROME_PORT_FILE 指定一个自定义位置；不扫描凭据目录、不读取 Cookie 数据库、不启动或刷新浏览器。
- 同一授权 socket 枚举页面，按现有平台 URL 白名单匹配。唯一页面自动选中；多个页面返回有界、无 URL 查询参数的选择项，由用户选择后再次连接；Chrome 可能要求再次授权。无匹配页面提供打开官网并登录的指引，不擅自操作页面。
- 手动路径与目标 ID 留在折叠的高级设置。浏览器未开启远程调试、未打开受支持页面分别给出可执行提示，不笼统归因于退出登录。
- 连接和获取由一次明确动作授权；只读状态、筛选及组件挂载不能发布任务。幂等、取消、失败部分入库、平台隔离均复用现有机制。

## 后果与验收

无需日常填写调试字段；自定义浏览器配置和多个页面仍需要一次选择。Chrome 授权、智联／猎聘初始化操作以及前程无忧官网批次前置条件保留。使用模拟 CDP、应用测试和隔离浏览器 UI 验证自动定位、歧义选择、会话复用、冻结保护及不重复获取；不以此宣称上游长期稳定。
