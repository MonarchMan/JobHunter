# ADR-0001：TypeScript 模块化单体

- 状态：Superseded by ADR-0007
- 日期：2026-08-19

## 决策

首期统一使用 Node.js 22+、TypeScript 严格模式和 pnpm workspace，以模块化单体组织代码。CLI、Worker 和后续 Web 是独立入口，共享应用层与领域包。

## 原因

首期以 Web、浏览器采集、数据管道和模型 API 编排为主，统一语言可以共享 Schema 和类型并降低个人维护成本。微服务不会带来与当前规模相称的收益。

## 后果

跨包只能使用公开入口，领域层不得依赖具体基础设施。若未来出现必须使用 Python 的模型训练或重型 NLP，可通过任务/数据端口增加独立服务，不改变现有领域边界。
